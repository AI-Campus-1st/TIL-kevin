## 1. 90일치 기상 센서 로그를 직접 생성해 결측값·이상치를 보정하고 월별 리포트 만들기

### 정답

```py
import numpy as np
import pandas as pd

# ① 랜덤 시계열 Series 생성
np.random.seed(2024)

dates = pd.date_range('2024-03-01', periods=90, freq='D')
values = np.random.normal(18, 4, 90).round(1)
s = pd.Series(values, index=dates)

print(s.head())
print(s.describe())
print(s.index)
print(s.dtype)

# 결측값 주입
miss_idx = np.random.choice(s.index, size=10, replace=False)
s[miss_idx] = np.nan

# 이상치 주입
out_idx = np.random.choice(s[s.notnull()].index, size=5, replace=False)
s[out_idx] = s[out_idx] * 3

# ② 결측값 보정 방식 4가지 비교
print(s[s.isnull()].index)
print("결측 개수:", s.isnull().sum())

s_drop  = s.dropna()
s_zero  = s.fillna(0)
s_mean  = s.fillna(s.mean())
s_ffill = s.ffill()          # 버전 오류가 발생하는 경우 다음 코드 사용, s.fillna(method='ffill')

comp = pd.DataFrame({
    '제거':     [s_drop.mean(),  s_drop.std()],
    '0채움':    [s_zero.mean(),  s_zero.std()],
    '평균채움': [s_mean.mean(),  s_mean.std()],
    '앞값채움': [s_ffill.mean(), s_ffill.std()],
}, index=['평균', '표준편차'])
print(comp.round(2))
# 0으로 채우는 방식이 가장 부적절하다. 기온 0도는 실제로 가능한 값이라
# 결측인지 관측값인지 구분되지 않고, 평균을 끌어내리며 표준편차를 크게 부풀린다.

base = s_ffill

# ③ 이상치 탐지와 보정
lo = base.mean() - 2 * base.std()
hi = base.mean() + 2 * base.std()
print("하한:", round(lo, 2), "상한:", round(hi, 2))

print(base[(base < lo) | (base > hi)])   # 주입한 5일과 일치

clean = pd.Series(np.where(base > hi, hi,
                  np.where(base < lo, lo, base)), index=base.index)

print(base.describe())
print(clean.describe())
# 극단값이 상한으로 눌리면서 표준편차가 크게 줄고 평균도 낮아진다.

# ④ 월별 집계와 이동평균
print(clean.groupby(clean.index.month).agg(['count', 'mean', 'min', 'max']).round(2))

roll = clean.rolling(7).mean()
print(roll.head(10))
# 7일치가 모여야 첫 평균이 나오므로 앞의 6개는 계산할 수 없어 NaN이 된다.

print(clean.sort_values(ascending=False).head(5))
print("평균 초과 일수:", len(clean[clean > clean.mean()]))
```

### 해설

- `np.random.normal`은 정규분포로 데이터를 랜덤으로 생성하고, `np.random.randint`의 경우 균등분포로 데이터를 생성합니다. 자연 현상과 관련된 데이터셋을 흉내낼 때에는 정규분포를 사용해야 함을 인지하는 것이 중요합니다.

- `np.random.choice`에서 `replace=False`를 사용하지 않으면, 복원 추출되어 결측 개수가 달라질 수 있습니다. 복원추출과 비복원추출에 대해서 알아두면 좋습니다.

- 이상치 주입 시, `np.nan`은 float 데이터타입을 가집니다. 따라서, 데이터 분석 시 정수형 필드의 칼럼은 결측치 유무에 따라 자료형이 바뀜을 인지해두시면 좋습니다.

- 이 과제의 핵심은 결측치를 채우는 전략에 대해서 생각해보는 것입니다. 결측 처리 방식에 따라 통계 수치가 달라지게 되고, 상황에 따라 어떤 전략을 사용해야 되는지를 이해하는 것이 중요합니다. 지금과 같이 시계열 데이터에서는 앞값으로 채우는 ffill 방식이 자연스러우며 이는 어제 기온과 오늘 기온은 비슷하다는 특징을 고려한 것입니다. 결측치가 있는 데이터 품질을 높이는데 사용할 수 있는 `interpolate()`는 주변값을 토대로 결측값을 보간하는 방법도 있습니다.

- 조건표현식처럼, np.where도 중첩하여 사용할 수 있습니다. `np.where(조건1, 값1, np.where(조건2, 값2, 값3))` 형태로 3분기 처리가 가능하고, `clip(lower=lo, upper=hi)`이라는 메서드도 한 번 활용해보세요.
    - 여기서 주의할 점은, np.where는 numpy 배열이기 때문에, series로 변환 시, index 설정을 주지 않으면 뒤의 `groupby(clean.index.month)`에서 오류가 났을 겁니다. 이 부분에 대해서 해결하는 것이 좀 어려웠을 수 있습니다.

- **`clean.index.month`** 처럼 DatetimeIndex는 `.year`, `.month`, `.day`, `.dayofweek` 같은 속성을 제공하고, 그것을 그룹화 기준으로 사용 가능합니다. 별도 열을 생성하여 처리했다면 그것도 괜찮습니다.

## 2. 300건 규모의 온라인 쇼핑몰 주문 데이터를 생성해 할인·배송비 정책을 반영한 정산표 만들기

### 정답
```py
import numpy as np
import pandas as pd

# ① 랜덤 주문 데이터 생성
np.random.seed(7)
n = 300

order_id   = ['ORD' + str(i).zfill(4) for i in range(1, n + 1)]
order_date = [pd.to_datetime('2024-01-01') + pd.DateOffset(d) for d in np.random.randint(0, 180, n)]
grade      = np.random.choice(['일반', '실버', '골드', 'VIP'], n, p=[0.5, 0.25, 0.15, 0.10])
category   = np.random.choice(['식품', '의류', '가전', '도서', '뷰티'], n)
qty        = np.random.randint(1, 6, n)
price      = np.random.choice([5000, 12000, 25000, 48000, 99000], n)
coupon     = np.random.choice([True, False], n, p=[0.3, 0.7])

df = pd.DataFrame({
    '주문번호': order_id, '주문일': order_date, '회원등급': grade,
    '카테고리': category, '수량': qty, '단가': price, '쿠폰사용': coupon
})
df = df.set_index('주문번호')

print(df.head())
print(df.info())
print(df.describe())
print(df['회원등급'].value_counts())

# 결측 주입 후 중앙값으로 보정
df['수량'] = df['수량'].astype(float)          # 정수형에 NaN을 넣기 전 실수형으로 변환
miss = np.random.choice(df.index, 20, replace=False)
df.loc[miss, '수량'] = np.nan
print("결측:", df['수량'].isnull().sum())      # 20
df['수량'] = df['수량'].fillna(df['수량'].median())
print("결측:", df['수량'].isnull().sum())      # 0

# ② 정산 로직을 파생 열로 구현
df['주문금액'] = df['수량'] * df['단가']

rate = {'일반': 0, '실버': 3, '골드': 5, 'VIP': 10}
df['등급할인율'] = df['회원등급'].map(rate)
df['쿠폰할인율'] = np.where(df['쿠폰사용'], 5, 0)
df['총할인율']   = df['등급할인율'] + df['쿠폰할인율']
df['할인금액']   = (df['주문금액'] * df['총할인율'] / 100).round(0)
df['배송비']     = np.where(df['주문금액'] - df['할인금액'] >= 30000, 0, 3000)
df['최종결제금액'] = df['주문금액'] - df['할인금액'] + df['배송비']

def size_label(m):
    if m >= 200000:
        return '대형'
    elif m >= 50000:
        return '중형'
    else:
        return '소형'

df['주문규모'] = df['최종결제금액'].apply(size_label)
print(df.head())
print(df['주문규모'].value_counts())

# ③ 집계와 조건 분석
df['월'] = df['주문일'].dt.month
print(df.groupby('월')['최종결제금액'].agg(['count', 'sum', 'mean']).round(0))
print(df.groupby(['카테고리', '회원등급'])['최종결제금액'].sum())

print(len(df[(df['회원등급'] == 'VIP') & (df['최종결제금액'] >= 100000)]))
print(df[df['쿠폰사용'] & (df['카테고리'] == '가전')])

top2 = df.sort_values(by=['카테고리', '최종결제금액'], ascending=[True, False]) \
         .groupby('카테고리').head(2)
print(top2[['카테고리', '최종결제금액']])

# ④ 정리와 저장
df.drop(['등급할인율', '쿠폰할인율'], axis='columns', inplace=True)
df.to_csv('orders.csv', encoding='utf-8-sig')

df2 = pd.read_csv('orders.csv', index_col='주문번호', header=0,
                  sep=',', parse_dates=['주문일'])
print(df2.dtypes)
print(df2.loc['ORD0010'])
print(df2.iloc[9])
# 주문번호가 생성 순서대로 부여되었고 행을 삭제하지 않았으므로
# 명시적 인덱스 'ORD0010'과 묵시적 인덱스 9(열 번째)가 같은 행을 가리킨다.
```

### 해설

- `np.random.choice(..., p=[...])`에서 p=를 통해 확률을 지정할 수 있습니다. 표본 수에 따라 확률을 지정한대로 정확히 일치하지 않을 수는 있습니다. `value_counts()`를 통해 설정값과 실제 비율을 확인해볼 수 있습니다.

- 랜덤으로 경과일을 설정하는 부분 처리를 어떻게 해야될지 고민하셨을 겁니다. pandas의 datetime으로 변환하는 `.to_datetime()`과, pandas에 `dateOffset()`을 활용하면 날짜에 일수를 더할 수 있습니다. 그 외에 `to_timedelta()`도 활용해볼 수 있습니다.

- 수량 부분 결측 주입 시 `fillna(median())`을 쓴 이유는 수량은 정수형이기 때문입니다.

- map, apply, where는 각각 필요에 따라 사용할 수 있습니다.
    - map의 경우 dictionary를 넣어서 매핑할 수 있으나 1:1로 대응되는 경우 활용하기 좋습니다. 대응값이 없을 때 NaN이 들어가는 위험이 있습니다.
    - np.where는 굳이 사용하지 않아도 되지만, 참 거짓 두 갈래에 따라 값이 분기되는 경우 사용할 수 있습니다.
    - apply도 사실 map처럼 함수를 전달하여 사용가능하고, 함수로 전달할 수 있으므로 복잡한 계산, 변환이 필요한 경우 활용할 수 있습니다.

- `.groupby()` 결과에 `.head()`를 사용해 상위 2건을 뽑을 수 있으며, 미리 `.sort_values()`로 정렬해 두어야 합니다.

- `df.drop([...], axis='columns', inplace=True)`를 활용해 여러 열을 한번에 지울 수 있으며, 지운 결과를 `inplace=True`를 통해 원본에 바로 적용할 수 있습니다.

- csv를 읽어오는 `read_csv()`에서, `parse_dates`라는 옵션을 활용하여 파일에 기록된 문자열을 pandas의 datetime type으로 가져올 수 있습니다.

## 3. 4개 분기 지점별 실적 데이터를 생성·연결해 MultiIndex 집계와 성장률 리포트 만들기

### 정답
```py
import numpy as np
import pandas as pd

# ① 분기 데이터 생성 함수 만들고 연결하기
np.random.seed(99)

branches = ['서울', '부산', '대구', '광주', '대전']
products = ['A', 'B', 'C']
quarters = ['1Q', '2Q', '3Q', '4Q']

def make_quarter(q):
    idx = pd.MultiIndex.from_product([branches, products], names=['지점', '상품'])
    data = {
        '판매량': np.random.randint(50, 300, len(idx)),
        '단가':   np.random.choice([10000, 15000, 20000], len(idx)),
        '반품':   np.random.randint(0, 20, len(idx)),
    }
    df = pd.DataFrame(data, index=idx)
    df['분기'] = q
    return df

sales = pd.concat([make_quarter(q) for q in quarters])
print(sales.shape)          # (60, 4)
print(sales.index.names)    # ['지점', '상품']
print(sales.head())

# 결측 주입 후 지점별 중앙값으로 보정
sales['판매량'] = sales['판매량'].astype(float)
drop_idx = np.random.choice(len(sales), 8, replace=False)
sales.iloc[drop_idx, sales.columns.get_loc('판매량')] = np.nan
print("결측:", sales['판매량'].isnull().sum())      # 8

med = sales.groupby('지점')['판매량'].transform('median')
sales['판매량'] = sales['판매량'].fillna(med)
print("결측:", sales['판매량'].isnull().sum())      # 0

# ② 파생 열과 MultiIndex 집계
sales['매출']   = sales['판매량'] * sales['단가']
sales['반품율'] = (sales['반품'] / sales['판매량'] * 100).round(2)
sales['등급']   = np.where(sales['매출'] >= 4000000, 'A',
                  np.where(sales['매출'] >= 2000000, 'B', 'C'))

print(sales.groupby('지점')['매출'].agg(['count', 'sum', 'mean', 'max']).round(0))
print(sales.groupby(['지점', '상품'])['매출'].sum())
print(sales.groupby(['분기', '지점'])['매출'].sum())
print(sales.groupby('등급').size())

# ③ 순위와 교차표(피벗)
total = sales.groupby('지점')['매출'].sum().sort_values(ascending=False)
print(total)
print(total.rank(ascending=False))

pv = sales.pivot_table(index='지점', columns='분기', values='매출', aggfunc='sum')
pv['연간합계'] = pv.sum(axis=1)
pv = pv.sort_values(by='연간합계', ascending=False)
print(pv)

pv['성장률'] = ((pv['4Q'] - pv['1Q']) / pv['1Q'] * 100).round(1)
print(pv[['1Q', '4Q', '성장률']].sort_values(by='성장률', ascending=False))

# ④ 가로 방향 연결과 저장
a = sales[sales['분기'] == '1Q'].groupby('지점')['매출'].sum()
b = sales[sales['분기'] == '4Q'].groupby('지점')['매출'].sum()
side = pd.concat([a, b], axis=1, keys=['1Q', '4Q'])
print(side)

top = sales.sort_values(by='매출', ascending=False).groupby('지점').head(1)
print(top[['분기', '매출', '등급']])

sales.to_csv('sales_report.csv', encoding='utf-8-sig')
r = pd.read_csv('sales_report.csv', index_col=['지점', '상품'], header=0)
print(r.head())
print(r.loc['서울'])
# loc으로 첫 번째 레벨(지점)을 지정하면 그 레벨이 사라지고
# 두 번째 레벨(상품)만 남은 단일 인덱스 DataFrame이 된다.
```

### 해설

- `pd.MultiIndex.from_product`은 두 리스트의 모든 조합을 자동으로 만들어 줍니다. 물론, list comprehension와 df.index.names를 활용하는것도 가능합니다.

- 기존에 사용하던 방식인 `groupby('지점')['판매량'].median()`은 지점 개수만큼만 판매량 중간값을 제공하기 때문에 `fillna()`에 바로 사용하는게 제약적입니다. `groupby().transform()`을 활용하면 원본의 데이터 개수만큼 나오게 되고, `fillna()`에 바로 적용할 수 있습니다.

- `pivot_table()`은 데이터를 pivot하여 사용자가 좀 더 보기 편하게 행열을 구성할 때 사용할 수 있으며, `aggfunc` 옵션으로 집계할 수 있습니다.

- `concat` 시 axis를 잘 확인하여야 합니다. 자주 헷갈리는 부분이기 때문에 결과 검증을 하고 넘어가는 것이 좋습니다.

- 실무에서의 조심할 사항으로는 ㅇㅇ률과 같이 나눗셈을 활용한 계산이 필요한 경우, 분모에 들어가는 열에 0이 있는지 확인하는 것이 중요합니다. 분모가 0인 행이 있으면, `inf`가 되므로 주의하여야 합니다.
