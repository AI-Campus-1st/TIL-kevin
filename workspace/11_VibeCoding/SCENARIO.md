# 서비스 이용 시나리오

## 1. 식단 생성 시나리오

진입 — 주말에 서비스 접속
이번 주 식단 생성 버튼을 누른다.

조건 확인 — 기본값을 활용해 필요한 정보만 선택
이번 주 요리할 날짜를 선택하고, 기본 설정된 평일 30분·주말 70분의 조리 시간을 필요할 때만 조정한다. 기본 식사 인원은 1명으로 유지한다.

생성 — 저장 레시피를 기반으로 주간 식단 추천
각 날짜의 조리 시간에 맞는 메뉴를 추천하고, 레시피명·예상 조리 시간·사용할 주요 재료를 함께 보여준다.

검토 및 수정 — 마음에 들지 않는 메뉴만 변경
바꾸고 싶은 날짜/메뉴 선택 후 요청사항을 입력하여 수정 요청. 다른 날짜의 식단은 유지

확정 — 식단 저장 및 장보기 목록 생성
마음에 드는 식단을 확정한다. 필요한 재료의 수량을 레시피 간 합산해 장보기 목록을 제공한다. 

## 2. 재료 구매 시나리오

장보기 목록 확인
확정된 주간 식단을 기반으로 공통 재료의 수량을 합산한 목록을 확인한다. 목록은 구매 시점에 따라 구분한다.

보유 재료 확인 (앱 바깥)
냉장고를 직접 확인하고 장보기 목록에서 이미 보유한 재료를 제외하거나 구매 수량을 조정한다. 별도의 재고 등록이나 지속적인 재고 관리는 하지 않는다.

부족한 재료 및 대체품 확인
구매가 필요한 재료의 대체품을 확인한다. 대체품을 선택하면 해당 레시피에 사용될 재료와 장보기 목록을 함께 업데이트한다.

- 대체 재료는 1~2개 정도 제안, 맛의 차이와 필요한 양에 대한 정보를 함께 제공
- 대체품 선택 시의 식단표 변경 (시스템, 기능적으로 해결)

장보기 목록에서 필요한 재료에 대해 쿠팡 검색 제공
- 사실 장보기에서 필요한 재료들 장바구니에 넣어놓으면 금액 맞춰서 주문만 하는건 어렵지 않음 (주문금액 자동계산 필요 X)

## 3. 요리 & 기록 시나리오

진입 및 메뉴 확인
앱에서 오늘의 메뉴를 확인하고 레시피를 연다. 재료, 조리 순서, 예상 시간과 필요한 곁들임 레시피를 확인한다.

요리 진행
레시피를 참고해 요리하고 식사한다. 조리 과정에서는 기록 입력을 요구하지 않는다.

요리 완료 표시
요리를 완료했음을 간단하게 표시한다. 기록은 선택 사항이며, 완료 표시만으로도 실제 요리한 레시피를 구분할 수 있다.

평가 및 개선점 기록
원할 때 별점과 간단한 개선 항목을 기록한다. 이후 같은 레시피를 선택하면 이전 메모를 다시 확인할 수 있다.
