# Core AI Development Guidelines

## 1. Architecture & Code Quality
- **Always follow Clean Architecture** to maximize code reusability, maintainability, and separation of concerns.
- Keep modules loosely coupled, responsibilities clearly defined, and dependencies explicit.
- Follow the specific design patterns and implementation rules defined in the frontend and backend guidelines.
- Avoid unnecessary complexity, duplication, and overengineering.

## 2. Development Workflow
- **Always follow Git workflow from start to finish.**
- Before starting, inspect the repository, check the current branch and working tree, and create or switch to an appropriate feature branch.
- Understand the existing architecture and conventions before making changes.
- Implement incrementally, validate changes, and run relevant tests and checks.
- Review the final diff, ensure changes are scoped and consistent, and commit with a clear, descriptive message.
- Never overwrite unrelated changes or commit directly to the main branch unless explicitly instructed.

## 3. Reporting
- Keep progress updates and final reports concise and actionable.
- Summarize key changes, validation results, and any blockers.
- Avoid lengthy explanations unless requested.
