# Project Instructions

## 1. Project Structure

```text
/
├── frontend/              # Frontend application
├── backend/               # Backend application and APIs
└── docs/
    ├── product/           # Product requirements and specifications
    └── design/
        ├── pages/         # Page-level designs and specifications
        └── components/    # Shared UI component specifications
```

## 2. Scope of Changes

- Frontend tasks should primarily target `frontend/`.
- Backend tasks should primarily target `backend/`.
- Update relevant documents in `docs/` when product requirements, page designs, or component specifications need to change.
- Avoid modifying unrelated directories or documents.
