# 단위체계 변환

> 범위: 원문 수량 표기를 수량·단위 코드로 바꾸고, 인분 환산·합산·표시 단위를 정하는 결정론적 로직
> 제외: API 엔드포인트·요청/응답 (API 명세에서 다룸)
> 관련: `./RECIPE_ANALYSIS.md` §5, `../BUSINESS_LOGICS.md` §4.4 장보기 계산, `../DATA_STRUCTURE.md` UNITS
> 사용자 안내: `docs/product/UNIT_GUIDE.md` — 레시피 상세 재료 영역의 `환산 규칙` 외부 링크로 연결 (`docs/design/pages/RECIPE_DETAIL.md`)
> 구현: `backend/app/domain/units.py`, 테스트: `backend/tests/domain/test_units.py`

---

## 1. 원칙

- 모든 변환은 `app/domain/`의 순수 Python 함수로 처리한다. LLM은 원문 문자열만 추출하고 숫자·단위를 바꾸지 않는다.
- 해석할 수 없는 값은 추정하지 않고 `null`로 두며 원문(`raw_amount`)을 항상 보존한다.
- 같은 차원 안에서만 환산한다. 무게 ↔ 부피, 개수 ↔ 무게는 바꾸지 않는다.

## 2. 단위 기준표

| 차원 | 기준 단위 | 단위 코드 (기준 단위 환산 계수) |
|---|---|---|
| 무게 `mass` | `g` | `g`(1), `kg`(1000) |
| 부피 `volume` | `ml` | `ml`(1), `L`(1000), `tsp` 작은술(5), `tbsp` 큰술(15), `cup` 컵(200) |
| 개수 `count` | 단위별 | `ea` 개, `clove` 쪽, `sheet` 장, `piece` 조각, `head` 통·포기, `bunch` 단·묶음, `handful` 줌, `pack` 봉지·팩, `can` 캔, `block` 모 |
| 비정량 `unmeasured` | 없음 | `pinch` 약간·조금·한 꼬집, `to_taste` 적당량·기호에 맞게 |

- 컵은 200ml
- 밥숟가락·티스푼처럼 계량 도구가 아닌 표기도 각각 큰술·작은술로 본다 (안내 문서에 명시)
- 기준표는 `units` 코드 테이블에 서버 시드로 관리한다

## 3. 변환 흐름

```text
원문 수량 표기 (raw_amount)        예: "1과 1/2숟갈"
   │
   ▼ 3.1 전처리      공백 정리, 전각 → 반각, 괄호 보조 표기 분리
   ▼ 3.2 수량 파싱   "1과 1/2" → 1.5
   ▼ 3.3 단위 정규화 "숟갈" → tbsp
   ▼
{ quantity: 1.5, unit_code: "tbsp", raw_amount: "1과 1/2숟갈" }
```

### 3.1 전처리

- 앞뒤·연속 공백 정리, 전각 숫자·기호를 반각으로
- 괄호 안 보조 표기는 분리해 보조 정보로만 사용: `"1컵(200ml)"` → 본 표기 `1컵`
- 수식어 제거: `"약 2큰술"`, `"2큰술 정도"` → `2큰술`

### 3.2 수량 파싱

| 원문 | 결과 | 규칙 |
|---|---|---|
| `2`, `1.5` | 2, 1.5 | 정수·소수 |
| `1/2`, `½`, `⅓` | 0.5, 0.333… | 분수·유니코드 분수 |
| `1과 1/2`, `1 1/2`, `한 개 반` | 1.5 | 대분수, "반" = 0.5 |
| `하나`, `두`, `세` | 1, 2, 3 | 한글 수사 (열까지) |
| `2~3`, `2-3` | 3 | 범위는 큰 값 (장보기 부족 방지) |
| `약간`, `적당량` | `null` | 비정량 → 3.3에서 `pinch` / `to_taste` |
| 해석 불가 | `null` | `raw_amount`만 보존 |

### 3.3 단위 정규화 (별칭 → 단위 코드)

| 단위 코드 | 별칭 |
|---|---|
| `g` | g, 그램, gr |
| `kg` | kg, 킬로, 킬로그램 |
| `ml` | ml, mL, cc, 미리, 밀리리터 |
| `L` | L, l, 리터 |
| `tbsp` | 큰술, T, Ts, Tbsp, 큰스푼, 밥숟가락, 밥숟갈, 숟가락, 숟갈, 스푼, spoon, spoons |
| `tsp` | 작은술, t, ts, tsp, 작은스푼, 티스푼, 찻숟가락, 찻술 |
| `cup` | 컵, C, cup |
| `ea` | 개, 알 |
| `clove` | 쪽, 톨 |
| `sheet` | 장 |
| `piece` | 조각, 토막 |
| `head` | 통, 포기 |
| `bunch` | 단, 묶음 |
| `handful` | 줌 |
| `pack` | 봉지, 팩, 봉 |
| `can` | 캔 |
| `block` | 모 |
| `pinch` | 약간, 조금, 한 꼬집, 꼬집, 소량 |
| `to_taste` | 적당량, 적당히, 기호에 맞게, 취향껏 |

- `T`(큰술)와 `t`(작은술)는 대소문자를 구분해 비교하고, 나머지는 대소문자 무시
- 매칭되지 않는 단위 → `unit_code = null` (원문 보존, 합산 제외)
- 수량만 있고 단위가 없으면 (`"양파 1"`) → `ea`로 간주

## 4. 인분 환산

- 필요량 = 기준 수량 × (계획 인분 ÷ 레시피 기준 인분)
- 기준 인분 또는 기준 수량이 `null`이면 필요량도 `null` ("수량 미확인")
- `unmeasured`는 인분 환산하지 않는다
- 계산값은 소수 그대로 유지하고 **표시할 때만** 반올림 (6장)

## 5. 합산 (장보기)

같은 재료(`ingredient_id`)의 필요량을 모을 때 적용한다. "마늘"과 "다진 마늘"은 다른 재료라 합산하지 않는다.

| 경우 | 처리 | 예 |
|---|---|---|
| 같은 차원 `mass`·`volume` | 기준 단위로 환산해 합산 | 2큰술 + 30ml → 60ml |
| 다른 차원 | 합산하지 않고 줄을 나눠 표시 | 간장 2큰술 + 간장 100g → 2줄 |
| `count` | 같은 단위 코드끼리만 합산 | 마늘 3쪽 + 마늘 1통 → 2줄 |
| `unmeasured` | 숫자와 합산하지 않고 "약간" 1회 표시, 정량이 있으면 옆에 병기 | 소금 1작은술 · 약간 |
| `quantity = null` / `unit_code = null` | 합산하지 않고 원문 또는 "수량 미확인"으로 별도 표시 | — |

## 6. 표시 단위와 반올림

**표시 단위**
- 합산된 값이 모두 같은 단위에서 왔으면 그 단위로 표시 (큰술 + 큰술 → 큰술)
- 단위가 섞였으면 기준 단위로 표시하고, 1000 이상이면 상위 단위 (1200g → 1.2kg, 1500ml → 1.5L)

**반올림**

| 단위 | 규칙 | 예 |
|---|---|---|
| `g`, `kg`, `ml`, `L` | 소수 첫째 자리까지 | 7.5g, 22.5ml |
| `tsp`, `tbsp`, `cup` | 1/4 단위로 반올림, 분수 표시 | 1.5큰술 → 1과 1/2큰술 |
| `count` | 0.5 단위로 올림 | 1.3개 → 1.5개 |
| `unmeasured` | 반올림 없음 | 약간 |

## 7. 테스트 기준 (단위 테스트 케이스)

| 입력 | 기대 결과 |
|---|---|
| `"1숟갈"` | 1, `tbsp` |
| `"1과 1/2큰술"` | 1.5, `tbsp` |
| `"1T"` / `"1t"` | 1, `tbsp` / 1, `tsp` |
| `"2~3개"` | 3, `ea` |
| `"½컵"` | 0.5, `cup` |
| `"200cc"` | 200, `ml` |
| `"약간"` | `null`, `pinch` |
| `"한 줌"` | 1, `handful` |
| `"주먹만큼"` | `null`, `null` (원문 보존) |
| 2큰술 + 30ml 합산 | 60ml |
| 기준 2인분 3큰술 → 3인분 | 4.5큰술 → "4와 1/2큰술" |

## 8. 확장 시 고려

- 재료별 밀도·개당 무게 정보가 생기면 차원 간 환산을 재료 단위로 허용할 수 있다 (MVP 제외)
- 새 단위 별칭은 운영 중 `raw_amount`의 미매칭 표기를 모아 주기적으로 추가한다
