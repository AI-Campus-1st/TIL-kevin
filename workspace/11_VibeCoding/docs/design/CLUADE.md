## 공통 컴포넌트
재사용 가능한 공통 컴포넌트는 `components/`에 분리했다. 원본 화면 명세에는 공통 동작을 반복 기재하기보다 해당 문서 경로를 참조하도록 정리했다.

- `BUTTON.md`
- `MODAL.md`
- `TOAST.md`
- `LINK.md`
- `ACCORDION.md`
- `STATUS_BADGE.md`
- `LIST.md`
- `TEXT_INPUT.md`
- `CHECKBOX.md`
- `TOGGLE_STEPPER.md`
- `TOOLTIP.md`
- `FLOATING_ACTION_BUTTON.md`
- `RECIPE_CARD.md`
- `BOTTOM_NAVIGATION.md`
- `WEEKLY_STATUS.md`

## 원칙
- 공통 컴포넌트 문서에는 재사용 규칙과 상태/동작을 정리한다.
- 화면 문서에는 해당 화면의 고유한 구성과 기능 흐름을 남긴다.
- `components/이름.md` 경로는 마크다운 상대 경로로 참조한다.
