# Button

## 목적
사용자가 화면 내 작업을 실행하거나 다른 화면으로 이동하도록 한다.

## 사용 위치
- 홈: `조리 시작`, `요리 완료`, `주간 식단 보기`, `식단 만들기`, `레시피 추가`, 평가 `등록` / `스킵`
- 주간 식단: `주간 식단 생성`, 날짜별 `식단 변경` / `식단 생성`, 모달 `취소` / 제출
- 레시피: `레시피 추가`, 상태별 `재시도`, `수정 요청`, `수정사항 반영 요청`, `확인 처리`
- 장보기: `대체 관리`, `쿠팡 검색`

## 구성
- 버튼 라벨
- 선택적으로 아이콘 또는 보조 설명
- 상태: 기본 / 비활성 / 로딩

## 동작 및 상태
- 클릭 시 명세된 액션만 수행한다.
- 필수 입력 누락 또는 선택 조건 미충족 시 비활성화하거나 오류를 안내한다.
- 제출 중에는 중복 제출을 방지하고 로딩 상태를 표시한다.
- destructive 액션은 일반 액션과 시각적으로 구분하고 확인 단계를 제공한다.
- 화면 이동 목적은 `Link`를 사용하고, 작업 실행 목적은 `Button`을 사용한다.

## 사용 원칙
- 같은 목적과 중요도의 액션은 화면 간 라벨·스타일·동작을 일관되게 유지한다.
- 고정 하단 액션은 화면의 주요 CTA에만 사용한다.
