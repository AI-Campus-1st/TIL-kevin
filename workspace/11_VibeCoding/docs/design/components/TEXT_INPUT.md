# Text Input

## 목적
사용자가 URL, 짧은 텍스트 또는 수정 요청을 입력하도록 한다.

## 사용 위치
- 레시피 추가 URL 입력
- 레시피 수정/반영 요청사항
- 주간 식단 변경 요청사항
- 요리 평가의 한 줄 코멘트

## 동작 및 상태
- 입력 목적을 명확히 하는 라벨 또는 안내 문구를 제공한다.
- 필수/선택 입력 여부를 표시한다.
- 입력값 검증이 필요하면 제출 시점에 명확한 오류를 안내한다.
- 요청 실패 시 사용자가 입력한 내용은 가능한 한 보존한다.
- 여러 줄 입력이 필요한 경우 `Text Area`를 사용한다.
