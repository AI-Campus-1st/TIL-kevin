# Weekly Status

## 목적
주간 식단의 생성 상태와 조회 맥락을 공통으로 표시한다.

## 사용 위치
- 주간 식단 화면
- 장보기 화면의 주간 식단 상태 영역

## 표시 정보
- 조회 중인 주간 날짜 범위
- 생성 상태: 생성 중, 일부 생성 완료, 전체 생성 완료, 실패
- 필요 시 해당 주에 확정 식단이 없어 장보기 목록이 아직 생성되지 않았음을 안내한다.

- **월 주차 표시**: `List` — 월을 주차별로 한 줄에 표시하고, 식단 존재 여부를 `Dot`으로 구분 (월 변경)
- **주차 상태**: `Dot` — 식단 존재 시 `Primary`, 없으면 `None`
- **생성 상태**: `Badge` — 식단 생성 완료 / 미배정 날짜 존재 표시

## 동작 및 원칙
- 상태 결과는 화면 내 상태 표시와 `Toast`로 안내한다.
- 일부 날짜만 실패한 경우 성공한 날짜는 유지하고 실패 날짜는 식단이 없는 상태로 표시한다.
- 전체 실패 시 기존 식단 및 장보기 목록을 임의로 초기화하지 않는다.
- 장보기 목록 갱신 실패 시 기존 목록을 유지한다.
