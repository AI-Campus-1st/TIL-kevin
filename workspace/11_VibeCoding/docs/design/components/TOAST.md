# Toast

## 목적
사용자의 작업 결과, 성공 여부 및 오류를 짧게 안내한다.

## 사용 위치
- 레시피 등록·수집·수정·삭제 결과
- 주간 식단 생성 및 날짜별 식단 변경 결과
- 재료 대체 적용 결과
- 요리 완료 및 평가 등록 결과
- 장보기 목록 갱신 또는 작업 오류

## 유형
- 성공: 작업이 정상적으로 완료됨
- 오류: 작업이 실패했거나 저장되지 않음
- 안내: 중복 항목, 일부 실패 등 후속 확인이 필요한 결과

## 구성
- 짧은 메시지
- 필요한 경우 다음 행동을 설명하는 액션(예: 재시도)

## 동작 및 상태
- 일시적으로 표시하고 자동으로 사라진다.
- 중요한 오류는 자동으로 사라지기 전에도 사용자가 내용을 읽을 수 있도록 충분한 시간을 둔다.
- 반복되는 동일 메시지는 과도하게 중복 표시하지 않는다.
- 오류 발생 시 기존 데이터가 유지되는지, 재시도가 가능한지 명확히 알린다.
- 복잡한 입력이나 상세한 오류 설명은 Toast에 넣지 않고 해당 화면 또는 Modal에서 안내한다.
