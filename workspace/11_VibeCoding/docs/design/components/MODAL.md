# Modal

## 목적
현재 화면을 벗어나지 않고 입력, 선택, 확인 작업을 완료하도록 한다.

## 사용 위치
- 주간 식단 생성
- 식단 변경 요청
- 레시피 추가
- 레시피 수정/반영 요청
- 요리 평가
- 재료 대체 관리 및 적용 확인
- 레시피 삭제 확인

## 공통 구성
- 제목
- 필요한 경우 설명 또는 대상 정보
- 입력 영역 또는 선택 항목
- 하단 액션 영역: 기본적으로 `취소`와 주요 액션
- 닫기 동작

## 동작 및 상태
- 주요 액션 실행 중에는 중복 제출을 막고 로딩 상태를 표시한다.
- 사용자가 입력한 값은 요청 실패 시 가능한 한 유지한다.
- 필수 입력이 누락된 경우 해당 입력 근처에 안내하고 제출을 막는다.
- 취소/닫기 시 저장되지 않은 변경사항은 반영하지 않는다.
- 삭제나 적용 범위가 중요한 작업은 실행 전 확인 정보를 제공한다.
- 결과 알림은 공통 `Toast`를 사용한다.

## 접근성 및 사용 원칙
- 열렸을 때 제목과 입력 영역이 명확해야 한다.
- 키보드 조작과 포커스 이동을 지원한다.
- 모바일에서는 화면 높이에 맞게 내부 콘텐츠를 스크롤할 수 있다.
