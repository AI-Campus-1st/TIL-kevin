# Shopping Screen Spec

## 1. 목적
확정된 주간 식단의 레시피를 바탕으로 필요한 재료를 확인하고, 준비 여부를 표시하며, 대체 재료를 관리하거나 쿠팡 검색으로 이동하는 화면이다.

## 2. 화면 구성

### Header
- 화면 제목: `장보기`
- 현재 주간 날짜 범위 표시 또는 주간 이동 컨트롤

### Status
- 주간 식단 생성 상태 표시
- 공통 상태 명세: `components/WEEKLY_STATUS.md`

### Summary
- 필요한 재료 수 등 장보기 목록 요약 표시
- 확정된 식단이 없는 경우 확정 식단 기반 목록이 아직 없음을 안내

### List
재료별 `Card` 또는 `List Item`을 표시한다.

각 재료 항목:
- 재료명
- 필요량 및 단위
- 준비 완료 여부는 `components/CHECKBOX.md` 기준으로 선택한다 (이미 보유했거나 구매를 완료한 경우 체크)
- 대체 재료 정보가 있으면 재료명 및 적용 상태
- 준비 완료 전 하단 액션 버튼 표시
  - 대체 재료가 있는 경우: `대체 관리` — 대체 후보 확인 및 적용
  - `쿠팡 검색`은 `components/LINK.md` 기준으로 해당 재료의 쿠팡 검색 결과로 이동
- 준비 완료 상태에서는 하단 액션 버튼을 숨김
- 레시피 출처 목록은 표시하지 않음

### 준비 여부 체크
- 재료별로 이미 보유했거나 구매를 완료했는지 여부만 관리한다.
- 체크하면 해당 재료는 구매 대상에서 제외하고 하단 액션 버튼을 숨긴다.
- 구매 수량을 별도로 입력하거나 관리하지 않는다.
- 레시피와 식단 변경으로 재료가 계속 필요한 경우 사용자가 설정한 준비 완료 여부를 유지한다.

## 3. 필요량 계산
- 확정된 날짜의 메인 레시피와 연결된 반찬 레시피를 기준으로 필요량을 계산한다.
- 레시피 기준량에 계획 인분과 기준 인분의 비율을 적용한다.
- 재료명이 정규화되고 단위가 호환되는 경우에만 합산한다.
- 재료별 필요량은 표시하되, 구매 수량 필드는 제공하지 않는다.
- 재료가 더 이상 필요하지 않으면 목록에서 제거한다.
- 새로 필요해진 재료는 기본 준비 미완료 상태로 추가한다.

## 4. 대체 재료
- 대체 재료는 선택한 날짜의 특정 레시피에만 적용한다. 다른 날짜나 다른 레시피에 전역 적용하지 않는다.
- 대체 후보 1~2개와 대체 비율/수량 정보를 표시한다.
- 수량이 불확실한 경우 적용 전에 사용자 확인을 요청한다.
- 적용 시 해당 레시피의 재료 관계와 장보기 필요량을 함께 갱신한다.
- 같은 재료를 사용하는 다른 레시피의 필요량은 유지한다.
- `대체 관리` 선택 시 후보 선택 및 적용 확인은 `components/MODAL.md` 기준으로 제공한다.
- 적용 결과 및 오류는 `components/TOAST.md` 기준으로 안내한다.

## 5. 쿠팡 검색
- 재료별 `쿠팡 검색` 액션으로 해당 재료의 쿠팡 검색 URL을 연다.
- 대체 재료가 적용된 경우 대체 재료명을 사용한다.
- 가격 확인, 장바구니 담기, 주문 기능은 제공하지 않는다.
- 여러 재료를 쿠팡 장바구니에 한 번에 담는 액션은 제공하지 않는다.

## 6. 상태 및 예외
- 확정된 식단이 없으면 식단 확정 후 목록이 생성된다는 안내를 표시한다.
- 식단 변경에 따른 목록 갱신은 원자적으로 처리한다.
- 갱신 실패 시 기존 장보기 목록을 유지한다.
- 재료 준비 여부는 목록 재계산 후에도 해당 재료가 계속 필요하면 유지한다.
- 작업 결과 및 오류는 `components/TOAST.md` 기준으로 안내한다.

## 7. 공통 컴포넌트 참조
- 재사용 컴포넌트의 동작과 공통 규칙은 `components/` 내 해당 문서를 기준으로 한다.
- 화면별 고유한 정보 구조와 동작은 본 문서의 앞선 항목을 기준으로 한다.
