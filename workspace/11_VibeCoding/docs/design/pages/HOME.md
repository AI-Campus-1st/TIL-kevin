# Home Screen Spec

## 1. Header

- 오늘 날짜만 표시한다.

## 2. Main — 오늘의 메뉴

### 오늘 날짜에 식단이 있는 경우

#### 오늘의 레시피 카드
- 레시피 이미지
- 레시피명
- 예상 조리 시간 배지
- `재료 정보` 접은 글은 `components/ACCORDION.md` 기준으로 제공
  - 계획 인분
  - 재료명 및 해당 인분 기준 필요량
- 하단 고정 `조리 시작` 액션은 `components/BUTTON.md` 기준으로 제공하며 상세 조리 화면으로 이동

#### 곁들임 레시피 목록
- 해당 날짜 식단에 연결된 곁들임 레시피가 있을 때 표시한다.
- 곁들임은 별도의 식사 시간대나 독립 식단으로 관리하지 않고, 해당 날짜의 식단에 연결된 레시피로 관리한다.
- 곁들임 레시피 선택 시 해당 레시피의 상세 조리 화면으로 이동한다.

#### 요리 완료 상태
- 완료 여부와 완료 시각을 표시한다.
- 완료된 식단은 완료 상태를 유지하고, 중복 완료 기록을 만들지 않는다.

### 오늘 날짜에 확정된 식단이 없는 경우

- `오늘 확정된 메뉴가 없습니다.` 표시
- `주간 식단 보기` 또는 `식단 만들기` 진입 버튼 제공
- 저장된 레시피가 없다면 레시피 등록 진입도 제공한다.

## 3. 레시피 등록

- `Floating Action Button`과 `Modal`의 공통 정의는 `components/FLOATING_ACTION_BUTTON.md`, `components/MODAL.md`를 따른다.
- `레시피 추가` 모달에는 URL 입력, `추가`, `취소`를 제공한다.
- 등록 결과 안내는 `components/TOAST.md`를 따른다.
- 등록한 레시피는 레시피 관리 화면에서 확인한다. 홈에서 추출 결과 검토나 레시피 상세 편집을 진행하지 않는다.

## 4. 상세 조리 화면

화면 레이아웃은 다음의 순서를 따름
- 레시피 이미지(있는 경우), 레시피명, 예상 조리 시간, 계획 인분 표시
- 조리 순서 표시
- 이전 평가·메모가 있으면 표시
- 곁들임 레시피가 연결되어 있으면 해당 레시피로 이동할 수 있는 링크/카드 제공
- 재료명과 계획 인분 기준 필요량 표시
- 하단 고정 `요리 완료` 액션은 `components/BUTTON.md` 기준으로 제공
- 요리 완료 시 해당 날짜 식단의 완료 상태와 완료 시각을 저장한다.

## 5. 요리 평가 모달

- 요리 완료 후 표시한다.
- 별점 선택 및 한 줄 코멘트 입력을 제공한다.
- `등록`과 `스킵` 액션은 `components/BUTTON.md` 기준으로 제공한다.
- 평가는 선택 사항이다. 스킵하거나 평가 저장에 실패하더라도 요리 완료 상태는 유지한다.
- 평가 등록 성공 시 토스트로 알린다.

## 6. 상태 및 오류 처리

- 데이터 로딩 중에는 메뉴 영역에 로딩 표시를 제공한다.
- 레시피 정보의 인분·필요량 등 일부 값이 확인되지 않으면 임의로 추정하지 않고 `미확인` 또는 `확인 필요`로 표시한다.
- 등록, 완료, 평가 저장 등 작업 결과와 오류는 `components/TOAST.md` 기준으로 알린다.
- 오류 토스트는 가능한 경우 재시도 등 다음 행동을 안내한다. 오류 발생 시 기존 식단이나 완료 상태를 임의로 변경하지 않는다.

## 7. Navigation

- 하단 내비게이션은 `components/BOTTOM_NAVIGATION.md` 기준으로 적용한다.


## 제외사항 (Don't)
- 문서에 나와있지 않은 모든 뱃지, 알림 아이콘, 공유 아이콘 등
- 식단 확정 여부 뱃지
