# Recipe Screen Spec

## 1. 목적
저장된 레시피를 확인하고, 외부 URL을 통해 레시피를 수집·관리하는 화면이다.

## 2. 화면 구성

### Header
- 화면 제목: `레시피`
- 레시피 추가 버튼은 Header에 배치하지 않는다.

### Category
- 카테고리 항목: `국` / `반찬` / `메인` / `간단` / `세트`
- 선택한 카테고리에 해당하는 레시피를 `List`로 표시한다.

### List
- 레시피 목록 요약은 표시하지 않는다.
- 저장된 레시피를 `List`로 표시한다.

각 레시피 항목:
- 레시피 이미지
- 레시피명
- 등록/수집 상태는 `components/STATUS_BADGE.md` 기준으로 표시: `수집 중`, `확인 필요`, `저장 완료`, `수집 실패`
- 조리 기록이 있는 경우 `components/ACCORDION.md` 기준으로 기록 표시
- 레시피 상태에 따른 액션
- 레시피 삭제 액션

### Floating Button
- 화면 하단의 추가 액션은 `components/FLOATING_ACTION_BUTTON.md` 기준으로 제공한다.
- 버튼명: `레시피 추가`
- 선택 시 `components/MODAL.md`에 정의된 레시피 추가 Modal을 연다.

### 레시피 추가 Modal
- 외부 레시피 URL 입력은 `components/TEXT_INPUT.md` 기준으로 제공하고 수집 요청 액션은 `components/BUTTON.md` 기준으로 제공한다.
- 추출 가능한 출처 안내는 `Tooltip`으로 표시한다.
- 툴팁 내용: `유튜브`, `만개의 레시피`, `네이버 블로그`
- 등록 결과 안내는 `components/TOAST.md` 기준으로 제공한다.
- 등록된 레시피의 상태는 `List`에서 확인한다.

### 레시피 수정/반영 Modal
- `확인 필요` 또는 `수집 실패` 상태에서 수정사항 반영을 요청할 수 있다.
- 사용자가 수정 요청사항을 직접 입력하는 영역은 `components/TEXT_INPUT.md` 기준으로 제공한다.
- `확인 필요` 상태에서는 다음 액션을 제공한다.
  - `수정사항 반영 요청`: `Text Box`의 요청사항을 제출한다. 요청사항은 선택 입력이다.
  - `확인 처리`: 레시피 정보를 확인하고 저장한다. 필수 항목인 `재료`가 입력되어 있어야 한다.
- `수집 실패` 상태에서는 `재시도`와 `수정 요청` 액션을 제공한다.
  - `재시도`: 기존 URL로 레시피 수집을 다시 실행한다.
  - `수정 요청`: `레시피 수정/반영 Modal`을 열고, `Text Box`에 입력한 요청사항을 바탕으로 수정을 요청한다.
- 필수 항목이 누락된 경우 해당 항목을 안내하고 확인 처리를 막는다.
- 제출 및 처리 결과 안내는 `components/TOAST.md` 기준으로 제공한다.

## 3. 상태 및 예외
- `수집 중`: `Badge`로 상태를 표시한다.
- `확인 필요`: 레시피 정보를 확인할 수 있도록 `수정사항 반영 요청`과 `확인 처리` 액션을 제공한다.
- `수집 실패`: `재시도`와 `수정 요청` 액션을 제공한다. `재시도`는 기존 URL로 수집을 다시 실행하고, `수정 요청`은 `Text Box`에 작성한 내용을 전달한다.
- 실패해도 사용자가 입력한 URL은 유지한다.
- 중복 URL인 경우 기존 레시피를 안내하고 해당 레시피를 확인할 수 있게 한다.
- 삭제 전 확인 `Modal`을 제공한다.
- 작업 결과 및 오류는 `components/TOAST.md` 기준으로 제공한다.

## 4. 검색 및 정렬
- 레시피 검색, 정렬, 분류 필터는 P1 범위로 둔다.
- 초기 버전에서는 카테고리 선택과 저장된 레시피 목록을 제공한다.

## 5. Don't
- Header에 `레시피 추가` 버튼을 배치하지 않는다.
- 레시피 목록 요약을 표시하지 않는다.

## 6. 관련 컴포넌트 유형
- `Header`
- `Category` / `Filter`
- `List` / `List Item`
- `Badge`
- `Accordion`
- `Floating Action Button`
- `Modal`
- `Tooltip`
- `Text Box`
- `Toast`
- `Search Field` (P1)
