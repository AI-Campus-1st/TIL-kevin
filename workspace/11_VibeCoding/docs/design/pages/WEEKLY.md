# Weekly Meals Screen Spec

## 1. 목적
한 주의 식단을 확인하고, 주간 식단을 생성하거나 날짜별 식단을 변경하는 화면이다.

## 2. 화면 구성

### Header
- 현재 조회 중인 주간 날짜 범위 표시
- 이전 주 / 다음 주 이동 버튼

### Status
- 주간 식단 생성 진행 상태는 `components/WEEKLY_STATUS.md` 기준으로 표시
- 생성 중, 일부 생성 완료, 전체 생성 완료, 실패 상태 구분
- 공통 상태 명세: `components/WEEKLY_STATUS.md`
- 생성 결과는 화면 내 상태와 `components/TOAST.md` 기준으로 안내

### Action Bar
- `주간 식단 생성` 액션은 `components/BUTTON.md` 기준으로 제공

### List
날짜별 식단은 `components/ACCORDION.md` 및 `components/LIST.md` 기준으로 표시한다.

각 날짜 항목:
- 날짜 및 요일
- 식단이 있는 날짜는 레시피 `Card`와 주요 정보를 표시
- 식단이 없는 날짜는 접힌 상태에서 식단이 있는 날짜보다 낮은 높이로 표시
- 항목을 열고 닫을 수 있음
- 식단이 있는 날짜를 열면 레시피 정보와 `식단 변경` 버튼 표시
- 식단이 없는 날짜를 열면 `식단 생성` 버튼 표시
- 연결된 반찬이 있을 경우 `components/ACCORDION.md` 기준의 접을 수 있는 영역에 레시피명 표시
- 날짜 또는 레시피 선택 시 해당 날짜의 요리 상세 화면으로 이동

## 3. 주간 식단 생성 모달

### Modal
- 제목: `주간 식단 생성`
- 안내 문구: 생성할 날짜와 각 날짜의 인분을 설정
- 요일별 설정을 묶는 `List`
- 하단 액션은 `components/BUTTON.md` 기준으로 제공하며, `취소`와 `식단 생성`을 포함한다.

### 요일별 설정 항목: List Item
각 요일별 항목은 다음 요소로 구성한다.
- 요일 및 날짜
- 요리 여부를 선택하는 `Toggle`
- 인분을 조절하는 `Stepper`

동작:
- 요일별로 요리 여부를 켜거나 끌 수 있다.
- 요리 여부를 끄면 해당 날짜의 `Stepper`를 비활성화한다.
- 요리 여부가 켜진 날짜에만 인분을 설정하고 식단 생성을 요청한다.
- 인분은 1 이상의 정수로 제한한다.
- 모든 요일의 요리 여부를 끈 경우 `식단 생성` 버튼을 비활성화하고 안내 문구를 표시한다.
- 생성 중에는 중복 제출을 방지한다.

### 생성 결과 처리
- 생성에 성공한 날짜의 식단은 즉시 확정한다.
- 일부 날짜만 실패하면 성공한 날짜는 유지하고, 실패한 날짜는 식단이 없는 상태로 표시한다.
- 생성 실패 시 기존 식단 및 장보기 목록을 임의로 초기화하지 않는다.
- 성공 및 실패 결과는 `Toast`로 안내하고, 날짜별 결과는 `List`에 반영한다.

## 4. 식단 변경 모달

### Modal
- 제목: `식단 변경`
- 현재 날짜와 식단 정보 표시
- 변경 요청사항을 입력하는 선택적 `Text Area`
- 하단 액션은 `components/BUTTON.md` 기준으로 제공하며, `취소`와 `변경 요청`을 포함한다.

동작:
- 변경 요청사항은 선택 입력이며, 비워 둔 상태에서도 제출할 수 있다.
- 제출 시 해당 날짜의 식단 변경을 요청한다.
- 제출 중에는 중복 제출을 방지한다.
- 변경 결과는 `Toast`로 안내하고, 성공 시 해당 날짜의 식단 정보를 갱신한다.
- 변경 실패 시 기존 식단을 유지하고 오류를 `Toast`로 안내한다.

## 5. 상태 및 예외
- 초기 로딩: 주간 식단 목록 로딩 상태 표시
- 빈 상태: 해당 주에 식단이 없음을 표시하고 `주간 식단 생성` CTA 제공
- 부분 실패: 생성 성공 날짜와 식단이 없는 날짜를 구분해 표시
- 전체 실패: 기존 데이터 유지 및 `Toast`로 실패 안내
- 작업 결과 및 오류는 `components/TOAST.md` 기준으로 안내

## 6. Don't
- 미배정 날짜 전용 재생성 버튼을 별도로 표시하지 않는다.
- 날짜별 식단이 없는 상태를 큰 카드로 표시하지 않는다.

## 7. 공통 컴포넌트 참조
- 재사용 컴포넌트의 동작과 공통 규칙은 `components/` 내 해당 문서를 기준으로 한다.
- 화면별 고유한 정보 구조와 동작은 본 문서의 앞선 항목을 기준으로 한다.
