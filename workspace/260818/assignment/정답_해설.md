## 1. 할리스커피 매장 정보 10페이지 수집

### 정답
```py
import time
import requests
import pandas as pd
from bs4 import BeautifulSoup

URL = "https://www.hollys.co.kr/store/korea/korStore2.do"
HEADERS = {"User-Agent": "Mozilla/5.0"}
DELAY = 0.7

def fetch(page):
    params = {"pageNo": page, "sido": "", "gugun": "", "store": ""}
    r = requests.get(URL, params=params, headers=HEADERS, timeout=10)
    r.raise_for_status()
    return r.text

def parse(html):
    soup = BeautifulSoup(html, "html.parser")
    rows = []
    for tr in soup.select("table.tb_store tbody tr"):
        td = tr.select("td")
        if len(td) < 6:          # '검색 결과가 없습니다' 행 방어
            continue
        services = [img.get("alt", "") for img in td[4].select("img")]
        rows.append({
            "지역": td[0].text.strip(),
            "매장명": td[1].text.strip(),
            "현황": td[2].text.strip(),
            "주소": td[3].text.strip(),
            "매장 서비스": services,
            "전화번호": td[5].text.strip(),
        })
    return rows

result = []
for page in range(1, 11):
    rows = parse(fetch(page))

    if not rows: # 빈 페이지면 조기 종료
        print(f"{page}페이지가 비어 있어 중단합니다.")
        break

    result.extend(rows)

    print(f"{page}페이지 · 누적 {len(result)}건")

    time.sleep(DELAY)

pd.DataFrame(result).to_csv("hollys.csv", index=False, encoding="utf-8-sig")

print(result[:2])
```

### 해설

세 가지가 핵심입니다.

- 첫째, **페이지네이션 파라미터**입니다. `range(1, 11)`로 page 파라미터를 fetch 함수에 전달하고, 나머지 요소들은 요구사항에 없으니 일단 빈 값으로 전달합니다. page 파라미터를 관리할 때 `if not rows:` 부분은 페이지를 넘기다가 결과가 비면 멈추는 조건으로써 중간에 데이터가 없는 상황을 고려합니다.

- 둘째, **속성에서 값을 꺼내는 것**입니다. 매장 서비스는 텍스트가 아니라 아이콘 이미지로 표시되므로 `.text`로는 잡히지 않습니다. `img` 태그의 `alt` 속성을 읽어야 하고, 여러 개일 수 있으므로 list comprehension으로 모읍니다.

- 셋째, **방어적 파싱**입니다. `len(td) < 6` 검사가 없으면 검색 결과가 없는 페이지에서 `IndexError`로 크롤러가 멈춥니다. 크롤링을 할 때에는 현재 보이는 페이지의 형태만 확인하기보단, 마지막 페이지는 어떻게 데이터를 제공하는지 확인하는 습관이 필요합니다.

## 2. 알라딘 베스트셀러 수집

### 정답
```py
import requests
import pandas as pd
from bs4 import BeautifulSoup

URL = "https://www.aladin.co.kr/shop/common/wbest.aspx?BranchType=1"
HEADERS = {"User-Agent": "Mozilla/5.0"}
DELAY = 0.7

def pick(node, selector):
    """특정 요소가 없는 경우 빈 값 처리"""
    el = node.select_one(selector)
    return el.text.strip() if el else ""

def parse(html):
    soup = BeautifulSoup(html, "html.parser")
    rows = []
    for box in soup.select("div.ss_book_box"):
        img = box.select_one("img")
        rows.append({
            "카테고리": pick(box, "span.tit_category"),
            "제목": pick(box, "a.bo3"),
            "저자": pick(box, "li:nth-of-type(3)"),
            "정가": pick(box, "li:nth-of-type(4) > span"),
            "할인가격": pick(box, "span.ss_p2"),
            "이미지": img.get("src", "") if img else "",
        })
    return rows

result = []
for page in range(1, 11):
    r = requests.get(URL, params={'page': page},headers=HEADERS, timeout=10)
    r.raise_for_status()
    rows = parse(r.text)
    result.extend(rows)
    print(f"누적: {len(result)}건 수집")
    time.sleep(DELAY)

pd.DataFrame(result).to_csv("aladin_bestseller.csv",
                            index=False, encoding="utf-8-sig")
```

### 해설
- 정적 크롤링의 핵심은 결국 **반복되는 묶음을 먼저 잡고 그 안에서 재검색하는 것**입니다. 제목만 따로 전부 뽑고 저자만 따로 전부 뽑아 나중에 짝을 맞추면, 저자가 없는 책이 하나만 있어도 전체 순서가 어긋납니다. `div.ss_book_box`라는 책 한 권의 경계를 먼저 잡고 그 안에서 재탐색하면 이런 사고가 원천적으로 생기지 않습니다. 

- `pick()` 헬퍼 함수는 선택자가 없을 때 빈 문자열을 돌려줍니다. `select_one()`이 `None`을 돌려준 상태에서 `.text`를 부르면 `AttributeError`가 나는데, 혹시 모를 상황을 대비하여 이런 방어적 설계는 유용하게 동작합니다.

- 추가학습) 쿼리 파라미터는 서버에 데이터를 전달하는 방식중에 하나이고, 반드시 모두 전달할 필요는 없습니다. 해당 사이트에서 51- 순위를 눌러보았을 때, 여러 파라미터가 붙지만, page 파라미터만 전달해도 원하는 결과를 얻을 수 있습니다.
