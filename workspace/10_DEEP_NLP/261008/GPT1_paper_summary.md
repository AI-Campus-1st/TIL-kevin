# Improving Language Understanding by Generative Pre-Training (GPT-1)

## 논문 정보

- 저자: Alec Radford, Karthik Narasimhan, Tim Salimans, Ilya Sutskever (OpenAI)
- 발표: 2018 (OpenAI 기술 보고서)
- 제안 모델: GPT (Generative Pre-Training), 이후 GPT-1로 통칭

## 핵심 요약

- 레이블이 있는 데이터는 부족하고 레이블이 없는 텍스트는 풍부한 상황에서 출발
- 레이블 없는 대규모 텍스트로 언어 모델을 생성적 사전학습(generative pre-training)
- 사전학습된 모델을 각 과제의 레이블 데이터로 판별적 미세조정(discriminative fine-tuning)
- 모델 구조로 Transformer 디코더만 쌓은 구조 채택
- 과제별 입력을 하나의 토큰 시퀀스로 변환해 모델 구조 변경을 최소화
- 자연어 추론, 질의응답, 문장 유사도, 문장 분류 등 12개 과제 중 9개에서 최고 성능 갱신

## 1. Autoregressive Model

### 사전학습 목표

- 앞에 나온 토큰들을 조건으로 다음 토큰의 확률을 예측하는 표준 언어 모델 목표
- 고정 크기 문맥 범위 안에서 이전 토큰들로 현재 토큰의 로그 우도를 최대화
- 왼쪽에서 오른쪽 한 방향으로만 문맥을 참조하는 자기회귀(autoregressive) 방식
- 레이블 없이 텍스트 자체만으로 학습 신호를 얻는 비지도 학습

### 모델 구조

- 원래 Transformer의 디코더만 여러 층 쌓은 구조
- 인코더와 인코더-디코더 Attention이 없는 형태
- Masked Self-Attention으로 각 위치는 자신과 이전 위치만 참조
- 입력: 토큰 임베딩과 학습 가능한 위치 임베딩의 합
- 출력: 최종 층 출력에 Softmax를 적용해 다음 토큰의 확률 분포 산출
- 토큰화에 BPE(Byte Pair Encoding) 사용, 활성화 함수로 GELU 사용

### Transformer를 선택한 이유

- 기존 LSTM 기반 언어 모델 사전학습은 짧은 범위의 언어 구조만 포착
- Transformer는 장거리 의존 관계를 다루는 구조적 기억 능력이 우수
- 다양한 과제로 전이할 때 더 안정적인 성능 확보
- LSTM으로 대체한 비교 실험에서 평균 성능이 크게 하락

### 사전학습 데이터

- BooksCorpus: 미출간 도서 7천여 권으로 구성된 말뭉치
- 길게 이어지는 연속된 텍스트를 포함해 장거리 문맥 학습에 적합
- 문장 단위로 섞인 말뭉치(1B Word Benchmark)와 달리 문장 간 연결 구조 보존

## 2. Transfer Learning

### 2단계 학습 구조

- 1단계 비지도 사전학습: 레이블 없는 대규모 텍스트로 언어 모델의 초기 파라미터 학습
- 2단계 지도 미세조정: 사전학습된 파라미터를 출발점으로 각 과제의 레이블 데이터로 추가 학습
- 목표: 적은 조정만으로 다양한 과제에 전이 가능한 범용 표현 학습

### 기존 전이 방식과의 차이

- 단어 임베딩(Word2Vec, GloVe) 전이: 단어 수준 정보만 전달
- ELMo: 사전학습 표현을 고정된 특징(feature)으로 사용하고 과제별 모델을 별도로 설계
- GPT: 사전학습된 모델 전체를 그대로 사용하고 출력층 하나만 추가해 함께 미세조정
- 과제마다 별도 구조를 설계할 필요가 없는 과제 독립적(task-agnostic) 모델

### 미세조정 방식

- 마지막 Transformer 층의 출력에 선형 출력층 하나를 추가해 레이블 예측
- 새로 추가되는 파라미터는 출력층과 구분자 토큰 임베딩뿐
- 보조 목표: 미세조정 시 언어 모델 목표를 함께 학습
  - 일반화 성능 향상
  - 수렴 속도 향상
  - 큰 데이터셋에서 효과가 크고 작은 데이터셋에서는 효과가 적음

### 과제별 입력 변환(Task-Specific Input Transformations)

- 사전학습 모델은 연속된 단일 텍스트 시퀀스를 입력으로 학습
- 문장 쌍, 문서-질문-답변 등 구조화된 입력을 하나의 토큰 시퀀스로 변환
- 시작 토큰, 구분자 토큰, 종료 토큰을 추가해 구조 표현
- 문장 분류: 문장을 그대로 입력
- 자연어 추론: 전제와 가설을 구분자로 연결
- 문장 유사도: 두 문장에 순서가 없으므로 두 가지 순서를 각각 처리한 뒤 결과를 원소별로 합산
- 질의응답과 상식 추론: 문서, 질문, 후보 답변을 연결한 시퀀스를 답변 후보마다 만들고 Softmax로 정답 선택

### 전이 효과 분석

- 사전학습 층을 더 많이 전이할수록 성능이 계속 향상
- 사전학습 모델의 각 층이 과제 해결에 유용한 서로 다른 기능을 학습
- 사전학습 없이 같은 구조를 학습하면 모든 과제에서 성능이 크게 하락

## 3. Language Generation

### 생성적 사전학습의 의미

- 다음 토큰을 생성하는 언어 모델 목표 자체가 사전학습 과제
- 텍스트를 생성하도록 학습하는 과정에서 문법, 의미, 장거리 문맥 등 언어 이해에 필요한 지식 습득
- 논문 제목의 Generative Pre-Training은 생성 목표로 사전학습한다는 의미
- 논문의 평가 대상은 텍스트 생성 품질이 아닌 언어 이해 과제 성능

### 생성 모델과 판별 과제의 연결

- 사전학습: 생성적 목표(다음 토큰 예측)
- 미세조정: 판별적 목표(레이블 분류)
- 생성 능력을 학습한 모델이 분류, 추론, 질의응답 같은 판별 과제의 기반이 될 수 있음을 입증

### Zero-Shot 동작 분석

- 미세조정 없이 사전학습된 언어 모델만으로 과제를 수행하는 휴리스틱 실험
- 감성 분석: 문장 뒤에 특정 단어를 붙이고 긍정 단어와 부정 단어 중 확률이 높은 쪽 선택
- 문법 판단: 문장 전체의 토큰 평균 로그 확률로 문법 적합성 판단
- 질의응답: 문서와 질문을 조건으로 각 답변의 평균 로그 확률이 가장 높은 답변 선택
- 사전학습이 진행될수록 zero-shot 성능이 꾸준히 향상
- 언어 모델이 생성 학습만으로 다양한 과제 수행 능력을 점진적으로 습득한다는 근거
- LSTM은 같은 실험에서 성능 변동이 크며 Transformer 구조의 귀납적 편향이 전이에 유리함을 시사

## 결과

- 12개 과제 중 9개에서 기존 최고 성능 갱신
- 상식 추론(Story Cloze)과 질의응답(RACE)에서 특히 큰 폭의 향상
- 문법 판단(CoLA)에서 큰 폭의 향상, 언어 모델 사전학습이 언어적 지식을 학습함을 시사
- 소규모 데이터셋부터 대규모 데이터셋까지 고르게 효과 확인
- 앙상블 모델을 사용한 기존 방식보다 단일 모델로 우수한 결과 다수 확보
- 일부 소규모 자연어 추론 과제(RTE)에서는 기존 다중 과제 학습 모델보다 낮은 성능

## 의의

- 대규모 비지도 사전학습과 지도 미세조정을 결합한 2단계 학습 방식 정립
- Transformer 디코더 기반 자기회귀 언어 모델의 전이 학습 효과 입증
- 과제별 구조 설계 없이 입력 변환만으로 다양한 과제에 적용하는 방식 제시
- zero-shot 분석을 통해 언어 모델 사전학습만으로 과제 수행 능력이 생긴다는 방향 제시
- GPT-2, GPT-3로 이어지는 GPT 계열의 출발점
- 같은 해 발표된 BERT의 사전학습-미세조정 방식에 직접적 영향, BERT는 인코더 기반 양방향 구조로 차별화
