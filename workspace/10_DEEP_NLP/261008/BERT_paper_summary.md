# BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding

## 논문 정보

- 저자: Jacob Devlin, Ming-Wei Chang, Kenton Lee, Kristina Toutanova (Google AI Language)
- 발표: NAACL 2019 (arXiv 2018)
- 제안 모델: BERT (Bidirectional Encoder Representations from Transformers)

## 핵심 요약

- 기존 사전학습 언어 모델의 단방향 구조를 핵심 한계로 지목
- Transformer 인코더로 모든 층에서 왼쪽과 오른쪽 문맥을 동시에 참조하는 깊은 양방향 표현 학습
- 양방향 학습을 위해 MLM(Masked Language Modeling)과 NSP(Next Sentence Prediction) 두 가지 사전학습 과제 사용
- 사전학습 모델에 출력층 하나만 추가해 전체 파라미터를 미세조정하는 방식
- 문장 분류, 자연어 추론, 질의응답, 개체명 인식 등 11개 과제에서 최고 성능 갱신

## 1. Bidirectional Transformer

### 기존 방식의 한계

- 특징 기반 방식(ELMo): 사전학습 표현을 과제별 모델의 추가 특징으로 사용
- 미세조정 방식(GPT): 사전학습 모델 전체를 최소한의 파라미터 추가로 미세조정
- 두 방식 모두 단방향 언어 모델 목표로 사전학습
- GPT는 각 토큰이 왼쪽 문맥만 참조하는 구조로 양쪽 문맥이 필요한 과제에 불리
- ELMo는 순방향과 역방향 모델을 독립적으로 학습한 뒤 결과만 연결하는 얕은 양방향 구조

### BERT의 양방향 구조

- Transformer의 인코더를 여러 층 쌓은 구조
- Self-Attention에 Look-Ahead Mask가 없어 모든 위치가 앞뒤 문맥을 모두 참조
- 모든 층에서 왼쪽과 오른쪽 문맥을 동시에 결합하는 깊은 양방향 표현
- GPT와 동일한 크기의 BERT-Base를 두어 양방향 구조의 효과를 직접 비교

### 모델 크기

- BERT-Base: GPT와 같은 규모, 비교 실험용
- BERT-Large: 층 수, 은닉 차원, Attention head 수를 늘린 대형 모델
- 모델이 클수록 모든 과제에서 성능 향상
- 학습 데이터가 매우 적은 과제에서도 모델 크기 증가에 따른 성능 향상 확인

### 양방향 구조를 직접 학습할 수 없는 이유

- 일반적인 언어 모델은 이전 단어들로 다음 단어를 예측하는 조건부 확률 구조
- 양방향으로 학습하면 여러 층을 거치면서 예측 대상 단어가 간접적으로 자기 자신을 참조
- 정답을 미리 보는 문제가 생겨 예측 학습이 성립하지 않음
- 이 문제를 MLM으로 해결

## 2. Input Representation

### 단일 시퀀스 입력 구조

- 문장 하나 또는 문장 쌍을 하나의 토큰 시퀀스로 표현
- 문장 쌍 예시: 질문과 지문, 전제와 가설
- 여기서 문장은 언어학적 문장이 아닌 연속된 텍스트 구간을 의미

### 토큰화

- WordPiece 토큰화 사용
- 자주 등장하지 않는 단어를 하위 단어 단위로 분리해 표현
- 어휘 사전에 없는 단어도 하위 단어 조합으로 처리

### 특수 토큰

- [CLS]: 모든 시퀀스의 첫 번째 토큰, 최종 은닉 상태를 분류 과제의 시퀀스 표현으로 사용
- [SEP]: 문장 쌍에서 두 문장을 구분하고 시퀀스 끝을 표시

### 세 가지 임베딩의 합

- Token Embedding: 각 WordPiece 토큰의 임베딩
- Segment Embedding: 토큰이 문장 A와 문장 B 중 어디에 속하는지 표시
- Position Embedding: 토큰의 위치 정보, 학습 가능한 임베딩 사용
- 최종 입력 표현은 세 임베딩을 원소별로 더한 값

### Transformer 원 논문과의 차이

- Transformer는 고정된 사인·코사인 함수 기반 Positional Encoding 사용
- BERT는 학습 가능한 Position Embedding 사용
- 문장 쌍 처리를 위한 Segment Embedding 추가

## 3. Masked Language Modeling

### 기본 방식

- 입력 WordPiece 토큰의 15%를 무작위로 선택
- 선택한 토큰의 원래 단어를 예측하도록 학습
- 손실은 가려진 위치에 대해서만 계산
- 빈칸 채우기 과제(Cloze task)에서 착안

### 80/10/10 치환 규칙

- 선택된 토큰의 80%: [MASK] 토큰으로 치환
- 선택된 토큰의 10%: 무작위 단어로 치환
- 선택된 토큰의 10%: 원래 단어 유지

### 치환 규칙을 사용하는 이유

- [MASK] 토큰은 사전학습에만 존재하고 미세조정 입력에는 나타나지 않음
- 모두 [MASK]로 바꾸면 사전학습과 미세조정 사이의 입력 불일치 발생
- 어떤 토큰이 예측 대상인지, 어떤 토큰이 바뀌었는지 모델이 알 수 없음
- 결과적으로 모델이 모든 토큰에 대해 문맥 기반 표현을 유지하도록 학습
- 무작위 치환 비율이 전체 토큰 중 매우 작아 언어 이해 능력을 해치지 않음

### 학습 특성

- 배치마다 일부 토큰만 예측하므로 왼쪽에서 오른쪽 언어 모델보다 수렴이 다소 느림
- 학습 초기부터 단방향 언어 모델보다 높은 성능을 보여 느린 수렴의 단점 상쇄
- 미세조정 방식은 마스킹 비율 구성 변화에 강건
- 특징 기반 방식에서는 [MASK]만 사용할 때 성능 저하

## 4. Next Sentence Prediction

### 목적

- 질의응답, 자연어 추론 등 두 문장의 관계 이해가 필요한 과제 대비
- 언어 모델 목표만으로는 문장 간 관계를 직접 학습하기 어려움

### 학습 방식

- 문장 A와 문장 B를 하나의 시퀀스로 입력
- 50%: 실제로 A 다음에 이어지는 문장(IsNext)
- 50%: 말뭉치에서 무작위로 고른 문장(NotNext)
- [CLS] 토큰의 최종 은닉 상태로 두 문장의 연속 여부를 이진 분류

### 특성

- 사전학습 단계에서 매우 높은 정확도에 도달하는 단순한 과제
- 미세조정 전의 [CLS] 표현은 의미 있는 문장 표현이 아님
- 단순한 과제임에도 질의응답과 자연어 추론 성능에 기여

### 사전학습 데이터

- BooksCorpus와 영어 Wikipedia 사용
- Wikipedia는 목록, 표, 머리말을 제외한 본문만 사용
- 연속된 긴 시퀀스를 추출하기 위해 문장 단위로 섞인 말뭉치가 아닌 문서 단위 말뭉치 사용

## 5. Pre-training & Fine-Tuning

### 사전학습

- 레이블 없는 대규모 말뭉치로 MLM과 NSP를 동시에 학습
- 두 과제의 손실 합을 최소화

### 미세조정

- 사전학습된 파라미터로 모델 초기화
- 과제 입력과 출력을 BERT에 직접 연결하고 출력층 하나만 추가
- 모든 파라미터를 과제 레이블 데이터로 end-to-end 학습
- 과제마다 별도 모델 구조 설계 불필요
- 사전학습 대비 매우 적은 계산 비용으로 미세조정 가능

### 과제 유형별 적용 방식

- 문장 분류, 문장 쌍 분류: [CLS] 최종 은닉 상태에 분류 층 추가
- 문장 쌍 과제: 두 문장을 한 시퀀스로 입력해 Self-Attention이 두 문장 간 상호 참조를 함께 처리
- 질의응답(SQuAD): 질문과 지문을 연결하고 각 토큰이 정답 시작 위치와 끝 위치일 확률을 계산해 정답 구간 추출
- 답이 없는 질문 처리: 정답이 없는 경우를 [CLS] 위치로 지정해 판단
- 개체명 인식 등 토큰 단위 과제: 각 토큰의 최종 은닉 상태에 분류 층 추가
- 다지선다 과제(SWAG): 문장과 후보마다 시퀀스를 만들고 [CLS] 점수를 Softmax로 비교

### 특징 기반 방식으로의 활용

- 미세조정 없이 BERT의 은닉 상태를 추출해 별도 모델의 입력 특징으로 사용 가능
- 상위 여러 층의 은닉 상태를 연결한 방식이 가장 우수
- 전체 미세조정과 근소한 차이의 성능 확보
- 미세조정 방식과 특징 기반 방식 모두에 효과적

## 결과

- GLUE, SQuAD v1.1, SQuAD v2.0, SWAG 등 11개 과제에서 최고 성능 갱신
- 같은 크기의 GPT보다 모든 GLUE 과제에서 우수
- 학습 데이터가 적은 과제에서 성능 향상 폭이 특히 큼
- 구성 요소 제거 실험 결과
  - NSP 제거 시 자연어 추론과 질의응답 성능 하락
  - 단방향 언어 모델로 대체 시 모든 과제에서 성능 하락, 특히 질의응답에서 크게 하락
  - 단방향 모델에 BiLSTM을 추가해도 양방향 사전학습에 미치지 못함
  - 순방향과 역방향 모델을 따로 학습해 결합하는 방식은 비용이 두 배이고 깊은 양방향 구조보다 표현력이 낮음

## 의의

- 깊은 양방향 사전학습의 효과를 실험으로 입증
- MLM으로 양방향 언어 모델 학습 문제 해결
- 과제별 구조 설계 없이 출력층 추가만으로 다양한 과제를 해결하는 범용 사전학습 모델 제시
- 인코더 기반 사전학습 모델(RoBERTa, ALBERT, ELECTRA 등) 연구의 출발점
- 디코더 기반 GPT 계열과 함께 사전학습-미세조정 방식을 NLP의 표준으로 정착
