# FastText 논문 요약

- 저자: Piotr Bojanowski, Edouard Grave, Armand Joulin, Tomas Mikolov (Facebook AI Research)
- 원문: https://arxiv.org/abs/1607.04606

---

## 핵심 요약

- 단어를 문자 n-gram의 집합으로 표현하는 Skip-gram 확장 모델 제안
- 단어 벡터는 해당 단어에 속한 n-gram 벡터의 합
- n-gram 벡터를 여러 단어가 공유하여 희귀 단어의 표현 품질 향상
- 학습 데이터에 없는 단어(OOV)도 n-gram 조합으로 벡터 생성 가능
- 형태 변화가 많은 언어에서 가장 큰 효과

## 키워드 간 관계

- Subword: 단어를 나누는 단위, 본 논문에서는 문자 n-gram 사용
- Character-level Embedding: 문자 n-gram마다 벡터를 학습하고 이를 합해 단어 벡터를 구성하는 방식
- Out-of-Vocabulary Handling: 위 두 요소의 결과로 얻어지는 능력, 미등록 단어도 n-gram 벡터로 표현 가능

## 배경: 기존 단어 임베딩의 한계

- word2vec 계열 모델은 단어마다 독립된 벡터 할당
- 단어 간 파라미터 공유 부재
- 단어의 내부 구조(어근, 접사, 어미) 무시
- 활용형이 많은 언어는 학습 데이터에서 드물게 등장하는 단어 형태가 다수
- 드문 단어는 학습 신호가 부족하여 벡터 품질 저하
- 학습 시 등장하지 않은 단어는 벡터 생성 불가

## 1. Subword

### 개념

- Subword는 단어보다 작은 문자열 단위
- 본 논문은 문자 n-gram을 subword로 사용
- 형태소 분석기 등 외부 언어 자원 없이 기계적으로 추출
- 기존 형태 기반 방법은 형태소 분해에 의존, 본 방법은 분해 과정 불필요

### n-gram 구성 방법

- 단어의 시작과 끝에 경계 기호 `<`, `>` 추가
- 경계 기호로 접두사와 접미사를 단어 중간의 동일 문자열과 구분
- 길이 3 이상 6 이하의 모든 문자 n-gram 추출
- 경계 기호가 붙은 단어 전체도 하나의 항목으로 포함
- 단어 고유의 표현과 n-gram 표현을 함께 학습

### n-gram 길이의 영향

- 3~6 범위는 여러 언어에서 안정적인 성능
- 긴 n-gram을 포함할수록 성능 향상 경향
- 복합명사가 많은 언어에서 긴 n-gram이 특히 중요
- 의미적 유추 작업에서도 긴 n-gram이 유리
- 2-gram은 정보 부족, 경계 기호와 문자 하나로만 구성되어 어미 표현 불가
- 최적 범위는 언어와 작업에 따라 상이하여 조정 필요

### 학습된 Subword의 성격

- 단어 표현에 가장 크게 기여하는 n-gram 분석
- 기여도가 높은 n-gram은 실제 형태소와 대체로 일치
- 복합어는 구성 단어 단위, 파생어는 접사 단위, 활용형은 어미 단위로 분리되는 경향
- 형태소 정보를 명시적으로 주지 않아도 형태 구조 학습

### 기존 형태 기반 방법과의 비교

- 형태소 분해 기반 방법들과 동일 데이터로 비교
- 대부분의 데이터셋에서 더 높은 성능
- 접두사/접미사 분석 기반 방법보다 우수, 차이의 원인은 복합명사 처리 능력

## 2. Character-level Embedding

### 2.1 본 논문의 위치

- 순수 문자 단위 모델과 구분
- 순수 문자 단위 모델은 단어 분절을 버리고 RNN, CNN이 문자 시퀀스를 직접 처리
- 본 논문은 단어 분절을 유지하고 단어 벡터를 문자 n-gram 임베딩으로 구성
- 문자 수준 정보를 단어 임베딩 학습에 결합하는 방식

### 기반 모델: Skip-gram with Negative Sampling

- 중심 단어로 주변 문맥 단어를 예측하도록 학습
- 문맥 단어 예측을 독립적인 이진 분류 문제로 변환
- 실제 문맥 단어는 양성 예제, 사전에서 무작위 추출한 단어는 음성 예제로 사용
- 기존 스코어 함수: 중심 단어 벡터와 문맥 단어 벡터의 내적

```
s(w, c) = u_w · v_c
```

### 스코어 함수의 변경

- 중심 단어 벡터를 n-gram 벡터의 합으로 대체
- 입력 쪽만 n-gram으로 분해, 문맥 쪽 벡터는 단어 단위 유지
- 학습 목적함수와 최적화 방식은 Skip-gram과 동일

### 파라미터 공유

- 같은 n-gram을 포함한 단어들은 해당 n-gram 벡터 공유
- 드문 단어도 다른 단어에서 학습된 n-gram 정보 활용
- 희귀 단어 표현 개선의 직접적인 원인

### 메모리 관리: 해싱

- 가능한 n-gram 종류가 매우 많아 전체 저장 시 메모리 부담 과다
- FNV-1a 해시 함수로 n-gram을 고정 크기 범위의 정수 인덱스에 매핑
- 단어는 사전 인덱스와 해시된 n-gram 인덱스 집합으로 표현
- 서로 다른 n-gram이 같은 벡터를 공유하는 충돌 발생 가능
- 충돌을 감수하고 메모리 사용량의 상한을 확보하는 설계

### 성능 특성

- 단어 유사도: 대부분의 데이터셋에서 기준 모델보다 우수
- 예외: 흔한 단어 위주로 구성된 영어 데이터셋, 이런 단어는 subword 없이도 좋은 벡터 확보 가능
- 단어 유추: 문법적(syntactic) 유추에서 큰 폭의 향상
- 의미적(semantic) 유추에서는 개선 부재, 일부 언어에서 하락
- 형태 변화가 많은 언어(독일어, 러시아어, 체코어, 아랍어)에서 큰 개선 폭
- 언어 모델의 임베딩 초기화에 사용 시 perplexity 감소, 슬라브어 계열에서 가장 큰 효과
- 학습 속도는 기준 모델보다 다소 느리나 대규모 코퍼스 학습이 가능한 수준

## 3. Out-of-Vocabulary Handling

### 기존 방식의 문제

- word2vec 계열 모델은 사전에 없는 단어에 벡터 부여 불가
- 평가 시 OOV 단어는 영벡터(null vector)로 대체
- 데이터가 적거나 형태 변화가 많은 언어일수록 OOV 비율 증가

### 제안 방식

- OOV 단어도 동일한 규칙으로 n-gram 분해 가능
- 학습된 n-gram 벡터를 합산하여 OOV 단어 벡터 생성 (정성 분석 절에서는 평균으로 기술)
- 추가 학습이나 외부 자원 불필요
- OOV를 영벡터로 처리한 경우는 sisg-, n-gram으로 벡터를 생성한 경우는 sisg로 구분

### 실험 결과

- sisg는 sisg-보다 모든 데이터셋에서 같거나 높은 성능
- 희귀 단어 데이터셋에서 기준 모델보다 우수
- 희귀 단어와 전문 용어의 최근접 이웃이 기준 모델보다 의미적으로 적절

### 학습 데이터 크기와의 관계

- 학습 데이터가 줄어들수록 OOV 비율 증가
- 기준 모델과 sisg-는 데이터 감소에 따라 성능 하락
- sisg는 작은 데이터에서도 높은 성능 유지
- 일부 데이터만 사용한 sisg가 전체 데이터를 사용한 기준 모델을 능가하는 경우 존재
- 데이터 증가에 따른 성능 향상은 빠르게 포화
- 작업 특화 데이터가 부족한 상황에서 높은 실용적 가치

### OOV 벡터의 내부 동작

- OOV 단어와 유사 단어 사이의 n-gram 단위 유사도 분석
- 의미가 대응하는 하위 문자열끼리 높은 유사도
- 기능이 같은 접미사끼리도 대응
- 사전에 없는 문법 형태의 접두사, 접미사는 무시되고 어근 중심으로 표현 형성
- OOV 벡터가 단순한 근사가 아닌 형태적으로 타당한 표현이라는 근거

---

## 4. 결론

- Skip-gram에 문자 n-gram 합산만 추가한 단순한 구조
- 전처리, 형태소 분석, 지도 정보 불필요
- 형태 정보 활용, 희귀 단어 개선, OOV 처리를 하나의 구조로 달성
- 형태 분석 기반 기존 방법보다 우수한 성능
- 구현체는 fastText라는 이름으로 공개
