# word2vec 논문 요약

- 저자: Tomas Mikolov, Kai Chen, Greg Corrado, Jeffrey Dean (Google)
- 원문: https://arxiv.org/abs/1301.3781

---

## 핵심 요약

- 비선형 은닉층을 없앤 단순한 로그-선형 모델 2종(CBOW, Skip-gram) 제안
- 기존 신경망 언어 모델 대비 계산 비용 대폭 감소
- 수십억 단어 규모 데이터로 고품질 단어 벡터 학습 가능
- 단어 간 의미 관계와 문법 관계를 선형 연산으로 표현

## 1. Word Embedding

### 핵심
- 단어를 실수 벡터 공간의 한 점으로 표현하는 방식
- 단어 간 유사성을 벡터 간 거리로 처리 가능

### 기존 방식의 한계
- 기존 NLP 시스템은 단어를 원자 단위로 취급
- 단어를 어휘 사전의 인덱스로만 표현
- 단어 간 유사성 개념 부재
- 대량 데이터로 학습하는 단순 모델(N-gram)은 데이터가 제한된 분야에서 성능 한계 도달

### 분산 표현으로의 전환
- 대안으로 분산 표현(distributed representation) 사용
- 신경망 기반 언어 모델이 N-gram 모델보다 우수
- 기존 NNLM은 단어 벡터와 언어 모델을 함께 학습
- 본 논문은 단어 벡터 학습 단계만 분리하여 단순한 모델로 수행

### 논문의 목표
- 수십억 단어의 데이터와 수백만 단어의 어휘에서 단어 벡터를 학습하는 기법 제시
- 기존 아키텍처의 이 규모 학습 성공 사례 부재

---

## 2. Continuous Word Vectors

### 핵심
- 유사한 단어가 서로 가까이 위치
- 단어 간 관계가 벡터 차이로 일정하게 표현
- 이 선형 규칙성 보존이 설계 목표

### 다중 유사도
- 한 단어가 여러 종류의 유사성을 동시에 보유
- 문법적 규칙성(형태 변화)과 의미적 규칙성(개념 간 관계)이 모두 벡터 공간에 반영

### 벡터 오프셋 연산
- 단어 벡터의 덧셈과 뺄셈으로 단어 관계 추론
- 계산식: `vector(B) - vector(A) + vector(C)`
- 계산된 벡터와 코사인 거리가 가장 가까운 단어를 답으로 선택
- 질문에 사용된 입력 단어는 탐색 대상에서 제외

### 평가 방법
- Semantic-Syntactic Word Relationship 테스트셋 신규 구축
- 의미 관계 질문과 문법 관계 질문으로 구성
- 정답 단어와 정확히 일치하는 경우만 정답 인정
- 동의어도 오답 처리

### 다른 표현 기법과의 관계
- 신경망 기반 분산 표현이 LSA보다 선형 규칙성 보존 성능 우수
- LDA는 대규모 데이터에서 계산 비용 과도

## 3. Skip-gram and CBOW

### 핵심
- 기존 신경망 언어 모델 계산량의 대부분은 비선형 은닉층에서 발생
- 은닉층 제거로 표현력 일부 포기
- 대신 훨씬 많은 데이터 학습 가능

### 기존 모델의 계산 병목
- 전체 학습 복잡도: `O = E × T × Q` (에폭 수, 학습 단어 수, 모델별 연산량)
- NNLM의 병목: 투영층과 은닉층 사이 연산(`N × D × H`)
- RNNLM의 병목: 은닉층 간 순환 연산(`H × H`)
- 출력층 연산(`H × V`)은 계층적 소프트맥스로 `log2(V)` 수준까지 감소 가능
- 어휘를 허프만 트리로 구성하여 빈도가 높은 단어에 짧은 코드 부여
- 은닉층이 없는 새 모델은 이 소프트맥스 효율에 크게 의존

### CBOW (Continuous Bag-of-Words)
- 주변 단어로 중심 단어 예측
- 비선형 은닉층 제거
- 투영층을 모든 단어가 공유하며 문맥 단어 벡터의 평균 사용
- 단어 순서가 투영 결과에 영향을 주지 않으므로 Bag-of-Words로 명명
- 과거 단어와 미래 단어를 모두 입력으로 사용
- 일반 BoW와 달리 연속 분산 표현을 사용하므로 Continuous 명칭 부여
- 연산량: `Q = N × D + D × log2(V)`

### Skip-gram
- 중심 단어로 주변 단어 예측
- 예측 범위 확대 시 벡터 품질 향상, 계산량 증가
- 먼 단어는 관련성이 낮으므로 샘플링 빈도를 낮춰 가중치 감소
- 최대 거리 C 안에서 무작위로 R을 정하고 앞뒤 R개 단어를 정답 레이블로 사용
- 연산량: `Q = C × (D + D × log2(V))`

### 두 모델 비교
- CBOW: 빠른 학습 속도, 문법 관계 성능 우수
- Skip-gram: 느린 학습 속도
- Skip-gram: 의미 관계 성능이 다른 모든 모델보다 크게 우수
- Skip-gram: 문법 관계 성능은 CBOW보다 약간 낮은 수준, NNLM보다는 우수

## 4. 실험 결과

- RNNLM 벡터가 최저 성능, 원인은 단어 벡터와 비선형 은닉층의 직접 연결
- CBOW는 문법 관계에서 NNLM보다 우수, 의미 관계에서는 유사
- 벡터 차원과 학습 데이터의 동시 확대 필요, 한쪽만 확대 시 개선 폭 급감
- 더 많은 데이터로 단일 에폭 학습 시 같은 데이터 여러 에폭 반복과 동등하거나 더 나은 결과
- 기존 공개 단어 벡터 대비 높은 성능과 훨씬 낮은 학습 비용
- DistBelief 분산 프레임워크로 대규모 데이터 학습 수행
- 문장 완성 과제에서 Skip-gram 단독 성능은 기존 기법 대비 열세
- Skip-gram과 RNNLM 결합 시 당시 최고 성능 달성

---

## 5. 결론

- 단순한 모델 구조로도 고품질 단어 벡터 학습 가능
- 낮은 계산 복잡도 덕분에 더 큰 데이터와 더 높은 차원의 학습 가능
- 분산 프레임워크 사용 시 사실상 제한 없는 어휘 크기로 확장 가능
- 이후 단일 머신 멀티스레드 C++ 구현을 word2vec으로 공개
- 후속 연구(Distributed Representations of Words and Phrases and their Compositionality)로 연결
- 고품질 단어 벡터가 이후 NLP 응용의 기본 구성 요소가 될 것으로 전망
