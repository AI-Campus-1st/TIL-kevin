# Sequence to Sequence Learning with Neural Networks (Seq2Seq)

## 논문 정보

- 저자: Ilya Sutskever, Oriol Vinyals, Quoc V. Le (Google)
- 발표: NIPS 2014
- 제안 모델: 다층 LSTM 기반 Sequence to Sequence 모델

## 핵심 요약

- 고정 차원 입출력만 다룰 수 있던 기존 DNN의 한계 해결
- 인코더 LSTM이 입력 시퀀스를 고정 차원 벡터로 압축하고 디코더 LSTM이 이 벡터로부터 출력 시퀀스 생성
- 시퀀스 구조에 대한 가정을 최소화한 범용 end-to-end 학습 방식
- 입력 문장의 단어 순서를 뒤집는 기법으로 학습 난이도 대폭 감소
- 대규모 영어-프랑스어 번역 과제에서 순수 신경망 번역으로 구문 기반 통계적 기계번역(SMT) 기준 시스템을 처음으로 능가

## 1. Encoder-Decoder 구조

### 기존 방식의 한계

- DNN은 입력과 출력을 고정 차원 벡터로 표현할 수 있는 문제에만 적용 가능
- 입력과 출력의 길이를 사전에 알 수 없는 시퀀스 문제에 직접 적용 불가
- 일반 RNN은 입출력 정렬 관계가 사전에 주어진 경우에만 시퀀스 대응 가능
- 입출력 길이가 다르고 대응 관계가 비단조적인 문제에는 적용 방법이 불명확
- 단일 RNN 두 개로 구성한 인코더-디코더는 장기의존성 문제로 학습이 어려움

### 인코더

- 입력 시퀀스를 한 시점씩 순서대로 읽는 LSTM
- 마지막 은닉 상태를 입력 시퀀스 전체를 대표하는 고정 차원 벡터로 사용
- 가변 길이 입력을 고정 차원 표현으로 변환하는 역할

### 디코더

- 인코더의 고정 차원 벡터를 초기 은닉 상태로 받는 LSTM 언어 모델
- 이전에 생성한 출력 토큰들과 인코더 벡터를 조건으로 다음 토큰의 확률 계산
- 각 시점의 출력 분포는 어휘 전체에 대한 Softmax로 표현
- 문장 끝 토큰(EOS)을 생성하면 출력 종료

### 구조 설계상의 특징

- 인코더와 디코더에 서로 다른 LSTM 사용
  - 계산 비용 증가 없이 파라미터 수 확대
  - 여러 언어쌍 동시 학습에 유리
- 얕은 LSTM보다 깊은 LSTM의 성능이 크게 우수해 4층 LSTM 채택
- LSTM은 기울기 소실에는 강하지만 기울기 폭주 가능성이 있어 기울기 노름 제한(gradient clipping) 적용

## 2. Machine Translation

### 실험 설정

- WMT'14 영어-프랑스어 번역 과제에 적용
- 두 가지 방식으로 평가
  - 직접 번역: SMT 시스템 없이 LSTM만으로 번역 생성
  - 재채점(rescoring): SMT 기준 시스템이 생성한 후보 번역 목록을 LSTM 확률로 재평가
- 양 언어 모두 고정 어휘 사전 사용, 사전 외 단어는 UNK 토큰으로 대체

### 학습과 번역 생성

- 학습 목표: 원문이 주어졌을 때 정답 번역의 로그 확률 최대화
- 번역 생성: 모델 기준으로 가장 확률이 높은 번역을 탐색
- 탐색 방식: 왼쪽에서 오른쪽으로 진행하는 빔 서치(beam search)
  - 매 시점 상위 후보 일부만 유지
  - 빔 크기가 작아도 대부분의 성능 확보
- 초기화가 다른 여러 LSTM의 앙상블로 최고 성능 확보

### 번역 성능

- 직접 번역에서 구문 기반 SMT 기준 시스템보다 높은 성능 달성
- 사전 외 단어를 처리하지 못하는 제약이 있음에도 SMT 기준 시스템을 능가
- 재채점 방식에서는 당시 최고 성능 시스템에 근접
- 긴 문장에서도 성능 저하가 거의 없음
- 희귀 단어가 많은 문장일수록 성능 저하

## 3. Sequence Transformation

### 시퀀스 간 변환 문제의 정식화

- 입력 시퀀스가 주어졌을 때 길이가 다를 수 있는 출력 시퀀스의 조건부 확률 추정
- 출력 시퀀스 확률을 각 시점 토큰 확률의 곱으로 분해
- EOS 토큰으로 가능한 모든 길이의 시퀀스에 대한 확률 분포 정의
- 시퀀스 구조에 대한 가정이 거의 없어 번역 외 음성 인식, 질의응답 등 시퀀스 대응 문제 전반에 적용 가능한 형태

### 입력 순서 반전(Reversing the Source Sentences)

- 원문 단어 순서만 뒤집고 번역문 순서는 유지한 상태로 학습
- 원문과 번역문의 대응 단어 간 평균 거리는 그대로 유지
- 원문 앞부분 단어와 번역문 앞부분 단어 사이의 거리가 크게 단축
- 단기 의존성이 다수 도입되어 역전파가 원문과 번역문 사이의 관계를 학습하기 쉬워짐
- 결과: 번역 성능의 큰 폭 향상, 긴 문장에서도 안정적인 번역
- 저자들은 메모리 활용 효율이 개선된 결과로 해석

### 학습된 문장 표현

- 가변 길이 문장을 고정 차원 벡터로 변환하는 능력 확보
- 의미가 비슷한 문장은 벡터 공간에서 가깝게, 의미가 다른 문장은 멀게 배치
- 단어 순서 변화에는 민감하게 반응
- 능동태와 수동태 전환에는 비교적 둔감
- 단어 순서를 고려하지 못하는 Bag-of-Words 방식과 구별되는 특성

## 결과

- 순수 신경망 번역이 대규모 번역 과제에서 SMT 기준 시스템을 처음으로 의미 있는 차이로 능가
- 어휘가 제한된 비교적 단순한 구조로도 어휘 제한이 없는 SMT 시스템보다 우수
- 입력 순서 반전만으로 번역 성능과 긴 문장 처리 능력 크게 향상
- 깊은 LSTM일수록 성능 향상
- 학습된 문장 벡터가 의미와 어순 정보를 반영

## 의의

- 가변 길이 시퀀스를 다른 가변 길이 시퀀스로 변환하는 범용 end-to-end 프레임워크 정립
- 신경망 기계번역(NMT) 연구의 출발점
- 단기 의존성을 늘리는 방향의 문제 인코딩이 학습 난이도를 낮춘다는 점 제시
- 고정 차원 벡터 하나에 입력 전체를 압축하는 구조의 한계는 이후 Attention 메커니즘 연구로 이어짐
