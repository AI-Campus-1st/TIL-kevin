# Neural Machine Translation by Jointly Learning to Align and Translate (Bahdanau Attention)

## 논문 정보

- 저자: Dzmitry Bahdanau, KyungHyun Cho, Yoshua Bengio (Jacobs University Bremen, Université de Montréal)
- 발표: ICLR 2015
- 제안 모델: RNNsearch (Attention 기반 인코더-디코더)

## 핵심 요약

- 기존 인코더-디코더 구조의 성능 병목으로 입력 문장 전체를 압축한 고정 길이 벡터를 지목
- 번역 단어를 생성할 때마다 입력 문장에서 관련 위치를 스스로 탐색하는 Attention 메커니즘 제안
- 입력 문장을 벡터 하나가 아닌 벡터 시퀀스로 인코딩하고 디코딩 시점마다 필요한 부분을 선택적으로 활용
- 정렬(alignment)과 번역을 하나의 신경망에서 동시에 학습
- 긴 문장에서 기존 인코더-디코더 대비 성능 저하가 크게 감소, 단일 모델로 구문 기반 SMT 시스템에 근접한 성능 달성

## 1. Attention Mechanism

### 기존 인코더-디코더의 한계

- 인코더가 입력 문장의 모든 정보를 고정 길이 벡터 하나에 압축하는 구조
- 문장 길이와 관계없이 동일한 크기의 벡터에 정보를 담아야 하는 제약
- 입력 문장이 길어질수록 번역 성능이 급격히 저하
- 학습 데이터보다 긴 문장에서 특히 취약

### Attention의 동작 방식

- 디코더가 번역 단어를 하나 생성할 때마다 입력 문장의 모든 위치에 대해 중요도 계산
- 중요도가 높은 입력 위치의 정보를 중심으로 다음 단어 예측
- 디코더가 입력 문장의 어느 부분에 집중할지 스스로 결정하는 구조
- 인코더가 모든 정보를 고정 길이 벡터에 담아야 하는 부담 해소
- 정보가 입력 시퀀스 전체에 분산 저장되고 디코더가 필요에 따라 선택적으로 조회

### 인코더: 양방향 RNN(BiRNN)

- 순방향 RNN은 입력을 처음부터 끝까지, 역방향 RNN은 끝에서 처음으로 읽기
- 각 단어 위치의 순방향 은닉 상태와 역방향 은닉 상태를 연결(concatenate)해 annotation 생성
- 각 annotation은 해당 단어의 앞 문맥과 뒤 문맥을 모두 요약
- RNN이 최근 입력을 더 잘 표현하는 특성상 annotation은 해당 단어 주변 정보에 집중
- 은닉 유닛으로 LSTM과 유사한 게이트 구조의 gated hidden unit(GRU 계열) 사용

## 2. Context Vector

### 기존 방식과의 차이

- 기존 인코더-디코더: 입력 문장 전체에 대해 하나의 고정된 context vector 사용
- 제안 모델: 출력 단어마다 서로 다른 context vector를 새로 계산

### Context Vector 계산 과정

- 정렬 점수(energy): 디코더의 직전 은닉 상태와 각 입력 위치의 annotation을 비교해 계산
- Attention 가중치: 정렬 점수를 Softmax로 정규화한 값
- Context vector: 모든 annotation을 Attention 가중치로 가중합한 벡터
- 디코더는 직전 출력 단어, 직전 은닉 상태, 현재 context vector를 바탕으로 다음 은닉 상태와 출력 단어 결정

### 확률적 해석

- Attention 가중치는 출력 단어가 각 입력 단어로부터 번역되었을 확률로 해석 가능
- Context vector는 가능한 모든 정렬에 대한 annotation의 기대값
- 가중치가 큰 annotation일수록 다음 단어 생성에 크게 반영

## 3. Alignment and Translation

### 정렬 모델(Alignment Model)

- 입력 위치 주변과 출력 위치가 얼마나 잘 대응하는지 점수화하는 모델
- 단층 피드포워드 신경망으로 구현
- 번역 모델의 다른 구성 요소와 함께 공동 학습

### Soft Alignment

- 전통적 기계번역은 정렬을 잠재 변수로 취급하고 번역 모델과 별도로 처리
- 제안 모델은 정렬을 확률 분포 형태의 soft alignment로 직접 계산
- 미분 가능한 구조여서 비용 함수의 기울기가 정렬 모델까지 역전파
- 정렬 모델과 번역 모델 전체를 하나의 목적 함수로 공동 학습
- 하나의 입력 단어를 하나의 출력 단어에 고정 대응시키는 hard alignment와 달리 여러 입력 단어를 동시에 참고 가능
- 입력과 출력의 구 길이가 서로 달라도 별도 처리 없이 자연스럽게 대응

### 정렬 분석 결과

- Attention 가중치 시각화로 출력 단어별 참조한 입력 위치 확인 가능
- 영어-프랑스어 정렬은 대체로 단조로운 대각선 형태
- 형용사와 명사 어순이 다른 경우 등 비단조적 정렬도 정확히 학습
- 언어학적으로 타당한 정렬을 별도 정렬 정답 없이 학습

## 4. Variable-Length Input Handling

### 가변 길이 입력의 표현 방식

- 기존 방식: 가변 길이 입력을 고정 길이 벡터로 변환
- 제안 방식: 입력 길이만큼의 annotation 시퀀스, 즉 가변 길이 표현으로 인코딩
- 입력이 길어지면 annotation 수도 함께 증가해 정보 손실 감소
- 디코더는 매 시점 annotation 전체를 대상으로 필요한 부분만 선택

### 긴 문장에서의 효과

- 기존 인코더-디코더는 문장 길이가 증가할수록 성능이 급격히 하락
- 제안 모델은 문장 길이 변화에 강건한 성능 유지
- 긴 문장으로 학습한 제안 모델은 매우 긴 문장에서도 성능 저하가 거의 없음
- 짧은 문장으로 학습한 제안 모델이 긴 문장으로 학습한 기존 모델보다 우수
- 긴 문장 전체를 완벽히 압축할 필요 없이 특정 단어 주변 정보만 정확히 인코딩하면 되는 구조 덕분

### 한계

- 출력 단어마다 입력 문장의 모든 단어에 대해 가중치를 계산해야 하는 구조
- 입력과 출력 길이의 곱에 비례하는 계산량
- 번역처럼 문장 길이가 짧은 과제에서는 문제가 크지 않으나 다른 과제 적용 시 제약 가능
- 미등록 단어와 희귀 단어 처리는 향후 과제로 제시

## 결과

- 모든 실험 조건에서 제안 모델이 기존 RNN 인코더-디코더보다 우수
- 미등록 단어가 없는 문장 기준 구문 기반 SMT 시스템(Moses)과 대등한 성능
- Moses가 추가 단일 언어 말뭉치를 사용한 것과 달리 병렬 말뭉치만으로 달성
- 긴 문장에서 기존 모델이 원문 의미에서 벗어나는 반면 제안 모델은 의미를 유지한 번역 생성
- 학습된 soft alignment가 직관적으로 타당한 단어 대응 관계 형성

## 의의

- Attention 메커니즘을 신경망 기계번역에 처음 도입한 연구
- 고정 길이 벡터 병목을 해소해 인코더-디코더 구조의 표현 한계 개선
- 정렬과 번역을 분리하던 기존 기계번역과 달리 전 과정을 end-to-end로 공동 학습
- Attention 가중치 시각화를 통한 모델 동작 해석 가능성 제시
- 이후 Luong Attention, Self-Attention, Transformer로 이어지는 Attention 계열 연구의 출발점
