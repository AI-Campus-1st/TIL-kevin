# Deep Contextualized Word Representations (ELMo)

## 논문 정보

- 저자: Matthew E. Peters 외, Allen Institute for AI, University of Washington
- 발표: NAACL 2018
- 제안 모델: ELMo (Embeddings from Language Models)

## 핵심 요약

- 단어마다 고정 벡터 하나를 부여하던 기존 임베딩의 한계 해결
- 문장 전체를 입력받아 문맥에 따라 달라지는 단어 표현 생성
- 대규모 말뭉치로 사전학습한 양방향 LSTM 언어 모델(biLM)의 내부 상태 활용
- 최상위 층만 사용하지 않고 모든 층의 출력을 과제별 가중합으로 결합
- 기존 모델 입력에 추가하는 방식만으로 6개 NLP 과제 모두에서 최고 성능 갱신

## 1. Contextual Word Representations

### 기존 방식의 한계

- Word2Vec, GloVe 등 사전학습 단어 벡터는 단어당 하나의 문맥 독립적 표현만 제공
- 동일 단어가 문맥에 따라 다른 의미를 갖는 다의성 반영 불가
- 고정된 어휘 사전 기반으로 사전에 없는 단어 처리에 한계

### ELMo의 표현 방식

- 각 토큰의 표현을 입력 문장 전체의 함수로 정의
- 같은 단어라도 문장이 달라지면 서로 다른 벡터 산출
- 목표: 단어의 문법적·의미적 특성과 문맥에 따른 용법 변화를 동시에 모델링
- 문자 단위 합성곱(character CNN)으로 입력을 구성해 학습 데이터에 없는 단어도 표현 가능
- 사전에 정의된 의미 분류 없이 다의어 정보를 하위 과제에 전달

### Deep 표현의 의미

- 이전 문맥 임베딩 연구(TagLM, CoVe)는 LSTM 최상위 층 출력만 사용
- ELMo는 biLM의 모든 층 출력을 결합한 표현을 deep 표현으로 정의
- 층별로 담는 정보 유형이 서로 다름
  - 하위 층: 품사 등 문법(syntax) 정보에 강점
  - 상위 층: 단어 의미(word sense) 등 문맥 의존적 의미 정보에 강점
- 모든 층을 노출해 과제별로 필요한 정보 유형을 선택하도록 구성

## 2. Bidirectional LSTM

### 양방향 언어 모델(biLM) 구조

- 순방향 LM: 이전 토큰들을 바탕으로 다음 토큰 예측
- 역방향 LM: 이후 토큰들을 바탕으로 이전 토큰 예측
- 두 방향의 로그 우도 합을 동시에 최대화하도록 학습
- 토큰 표현 층과 Softmax 층 파라미터는 두 방향이 공유
- LSTM 파라미터는 방향별로 독립 유지

### 사전학습 모델 구성

- 2층 biLSTM 구조
- 입력층: 문자 n-gram 합성곱 필터, highway 층, 선형 투영으로 구성된 문맥 독립 토큰 표현
- 첫 번째 LSTM 층과 두 번째 LSTM 층 사이 잔차 연결(residual connection) 적용
- 토큰마다 입력층과 2개 biLSTM 층, 총 3개 층의 표현 제공
- 대규모 단일 언어 말뭉치(1B Word Benchmark)로 사전학습
- 기계번역 인코더 기반 CoVe와 달리 병렬 말뭉치 크기 제약 없음

### 양방향 구조의 효과

- 한 토큰의 표현에 앞 문맥과 뒤 문맥이 모두 반영
- 층마다 순방향 은닉 상태와 역방향 은닉 상태를 연결(concatenate)해 해당 층의 표현 구성

## 3. Sentence-Level Embedding

### 문장 단위 입력 기반 임베딩

- 단어 하나가 아닌 문장 전체를 biLM에 입력해 각 토큰의 표현 계산
- 출력은 문장을 대표하는 단일 벡터가 아닌 문장 내 토큰별 벡터
- 문장 수준의 문맥 정보를 단어 단위 표현에 반영하는 방식

### ELMo 벡터 계산

- 각 토큰에 대해 biLM의 모든 층 표현을 하나의 벡터로 축약
- 층별 가중치: Softmax로 정규화한 과제별 학습 파라미터
- 스케일 파라미터(γ): 전체 ELMo 벡터 크기를 과제에 맞게 조정, 최적화 안정화에 기여
- 층별 활성값 분포 차이를 보정하기 위해 경우에 따라 층 정규화(layer normalization) 적용

### 하위 과제 모델 적용 방식

- biLM 가중치는 고정(freeze)한 상태로 사용
- 기존 모델의 문맥 독립 단어 벡터에 ELMo 벡터를 연결해 과제 모델 입력으로 사용
- 일부 과제에서는 과제 모델 RNN 출력에도 ELMo 벡터를 추가해 성능 추가 향상
  - attention 층이 뒤따르는 구조(SQuAD, SNLI)에서 효과
  - 의미역 결정, 상호참조 해결에서는 입력층에만 추가할 때 최고 성능
- ELMo 벡터에 dropout 적용, 층 가중치에 L2 정규화 적용
- 대부분 과제 도메인 데이터로 biLM을 미세조정(fine-tuning)한 뒤 고정해 사용

## 결과

- 질의응답, 텍스트 함의, 의미역 결정, 상호참조 해결, 개체명 인식, 감성 분석 6개 과제 모두 최고 성능 갱신
- 최상위 층만 사용하는 방식보다 모든 층을 결합하는 방식의 성능 우수
- 층 가중치를 과제별로 학습하는 방식이 단순 평균보다 우수
- 단어 의미 구분과 품사 태깅 모두에서 CoVe보다 풍부한 표현 확인
- 학습 데이터가 적을수록 성능 향상 폭 증가
- 목표 성능 도달에 필요한 학습 데이터 양과 학습 횟수 대폭 감소

## 의의

- 사전학습 언어 모델의 내부 표현을 하위 과제에 전이하는 반지도 학습 방식 정립
- 정적 임베딩에서 문맥적 임베딩으로 전환하는 계기
- 이후 BERT, GPT 등 사전학습 기반 언어 모델 연구의 기반
