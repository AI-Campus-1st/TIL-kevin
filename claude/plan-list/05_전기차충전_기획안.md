# [기획안 05] 서울 전기차 충전소 상태 및 충전 대기 중 주변 편의시설 연계 서비스

> 개발 조건: 수업 실습 프로젝트, 무료 공개 데이터만 사용, 서울 한정, 카카오맵 API 확보, 백엔드 Python FastAPI

## 1. 개요
- **프로젝트명**: 서울 전기차 충전소 상태 및 충전 대기 중 주변 편의시설 연계 서비스
- **추진 배경**
  - 충전소 위치·상태 표시는 지도 앱에서 이미 제공되지만, 충전 시간 동안 이용할 주변 시설과 충전소 혼잡 시간대 정보는 함께 제공되지 않음
- **목적**
  - 충전기 상태를 지도에 표시
  - 사용자 차량 정보로 예상 충전 시간을 계산하고, 그 시간 안에 걸어서 다녀올 수 있는 주변 편의시설을 추천
  - 상태 이력을 쌓아 충전소별 혼잡 시간대를 제공
- **차별점**: "체류 시간 기반 주변 시설 추천"과 "충전소 혼잡 시간대"를 핵심으로 정의
- **범위**: 서울특별시 공용 충전소 (이용자 제한 충전기는 기본 제외)

## 2. 주요 기능
1. **충전소 상태 지도**
   - 충전소별 사용 가능 충전기 수(급속·완속 구분)를 색상 마커로 표시, MarkerClusterer 적용
   - 상태 기준 시각 표시 (수 분 단위 갱신 데이터)
2. **충전소 상세**: 충전기별 상태, 출력(kW), 충전 방식, 운영시간, 이용 제한 여부
3. **충전 시간 계산 및 주변 편의시설 추천**
   - 입력: 배터리 용량(kWh), 현재 충전량(%), 목표 충전량(%), 차량 최대 충전 출력(kW, 선택)
   - 예상 충전 시간 = 배터리 용량 × (목표 − 현재) ÷ (실제 충전 출력 × 효율 0.9)
   - 실제 충전 출력 = min(충전기 출력, 차량 최대 충전 출력)
   - 급속 충전은 80% 이후 속도가 크게 줄어들므로 목표 80% 권장 문구 표시
   - 충전 시간에 맞춰 도보 반경 결정 (예: 30분 → 왕복 고려 반경 약 500m)
   - 반경 내 카페·음식점·편의점을 카카오 Places 카테고리 검색으로 조회해 CustomOverlay로 표시
4. **혼잡 시간대 차트**
   - 상태 이력으로 충전소별 요일·시간대 "사용 가능 충전기 비율" 평균 표시
   - 충전 대기 문제에 대응하는 기능 (대기 시간을 직접 예측하지는 않음)
5. **즐겨찾기 및 상태 알림**
   - 즐겨찾기 충전소는 브라우저에 저장 (로그인 없음)
   - 페이지가 열려 있는 동안 사용 가능 충전기가 생기면 브라우저 알림 (Notification API)
6. **경로상 충전소 추천 (선택 기능)**
   - 카카오모빌리티 길찾기 API 사용 권한 승인 시 구현
   - 경로 Polyline 반경 1km 내 충전소 중 사용 가능 급속 충전기가 있고 우회 거리가 짧은 순으로 추천

- **제공하지 않는 정보**: 충전기 예약 (공공 API 상태 정보에 예약 개념 없음)

## 3. 활용 데이터 및 API
| 데이터/API | 제공처 | 주요 정보 | 갱신·제약 | 활용 목적 |
| :--- | :--- | :--- | :--- | :--- |
| 한국환경공단 전기자동차 충전소 정보 (충전기 정보) | 공공데이터포털 | 충전소·충전기 ID, 위치, 출력, 충전 방식, 이용 제한, 운영시간 | 시도 코드로 서울 필터 | 충전소 목록, 상세 |
| 한국환경공단 전기자동차 충전소 정보 (충전기 상태) | 공공데이터포털 | 충전대기, 충전중, 통신이상, 운영중지, 점검중 등 | 수 분 단위 갱신 | 상태 표시, 이력 적재 |
| 카카오 Places 카테고리 검색 | Kakao Maps JS SDK services 라이브러리 | 카페(CE7), 음식점(FD6), 편의점(CS2) 반경 검색 | 일일 호출 한도 존재 | 주변 편의시설 |
| 카카오모빌리티 길찾기 API | 카카오모빌리티 개발자 사이트 | 자동차 경로, 경유지 | 사용 권한 신청 필요, 비상업 목적 무료 쿼터 | 경로상 충전소 (선택) |
| 서울 실시간 도시데이터 (충전소 현황) | 서울 열린데이터광장 | 주요 장소 주변 충전소 현황 | 주요 장소 한정 | 보조 정보 |

- **편의시설 데이터 선택 근거**: 소상공인 상가(상권)정보는 분기 갱신이며 영업시간·평점이 없어 카카오 Places 사용
- **확인 필요 사항**
  - 충전기 상태 코드 전체 목록과 의미
  - 상태 변경분만 조회하는 파라미터 지원 여부 (서울 전체 충전기를 매번 전량 조회하면 호출량 과다)
  - 카카오모빌리티 길찾기 API 권한 승인 소요 기간과 무료 쿼터 수치
  - 카카오 로컬(Places) 일일 호출 한도

## 4. 시스템 아키텍처 및 기술 스택
- **Frontend**
  - HTML5, CSS3, JavaScript (ES6+)
  - Kakao Maps JavaScript SDK (Marker, MarkerClusterer, CustomOverlay, Polyline, services 라이브러리)
  - Chart.js (혼잡 시간대 차트)
  - localStorage (즐겨찾기, 차량 정보), Notification API
- **Backend**
  - Python FastAPI (충전소 조회, 상태 조회, 혼잡 통계, 경로상 충전소 API)
  - APScheduler (충전기 정보 1일 1회, 상태 5분 주기 수집)
  - SQLite (충전기 목록, 최신 상태, 상태 이력)
- **Data Processing**
  - Pandas, NumPy (상태 이력 집계, 요일·시간대 평균)
  - Shapely (경로 버퍼 내 충전소 탐색, 선택 기능)

## 5. 개발 단계별 워크플로우

```
[1단계: 요구사항 정의 및 데이터 소스 식별]
  └─ 공공데이터포털 충전소 API 활용 신청, 카카오 도메인 등록
  └─ 카카오모빌리티 길찾기 API 사용 권한 신청 (승인 대기 동안 다른 단계 진행)
  └─ FastAPI 기초 실습

[2단계: 데이터 탐색 및 수집기 조기 가동]  ※ 혼잡 차트용 이력 확보를 위해 우선 진행
  └─ 충전기 정보 서울분 전체 수집, 이용 제한 충전기 구분
  └─ 상태 코드표 정리, 상태 수집기 5분 주기 가동 → SQLite 이력 적재
  └─ 최소 2주 이상 연속 수집

[3단계: 계산 로직 구현]
  └─ 충전 시간 계산 함수, 충전 시간 → 도보 반경 변환 함수
  └─ 요일·시간대별 사용 가능 비율 집계

[4단계: 백엔드 API 구축]
  └─ 지도 영역 내 충전소·상태 API, 충전소 상세 API, 혼잡 통계 API
  └─ 응답에 상태 기준 시각 포함

[5단계: 프론트엔드 및 카카오맵 연동]
  └─ 상태 색상 마커·클러스터, 상세 패널, 충전 시간 입력 폼
  └─ Places 반경 검색 결과 CustomOverlay, 혼잡 시간대 차트
  └─ 즐겨찾기·브라우저 알림

[6단계: 선택 기능]
  └─ 길찾기 API 승인 시 경로 Polyline + 경로 버퍼 내 충전소 추천

[7단계: 통합 테스트 및 검증]
  └─ 충전 시간 계산 결과를 차종 2~3개 공개 제원과 비교
  └─ 수집기 장시간 가동 안정성, API 장애 시 마지막 상태·기준 시각 표시 확인
  └─ 상태 반영 지연 시간 측정 (원천 갱신 시각 대비 화면 표시 시각)
```

## 6. 기대 효과 및 한계
- **기대 효과**
  - 충전 시간을 실제 체류 시간으로 바꾸어 주변 시설 이용 계획 지원
  - 혼잡 시간대 정보로 대기 가능성이 낮은 시간 선택 지원
- **한계**
  - 상태 정보는 수 분 단위 지연이 있어 도착 시점의 사용 가능 여부를 보장하지 않음
  - 충전 시간은 온도·배터리 상태에 따른 충전 속도 변화를 단순화한 추정치
  - 경로상 추천은 외부 API 권한 승인에 의존
