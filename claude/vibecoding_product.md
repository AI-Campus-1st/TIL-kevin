# 아이디어 도출법
### 순서
* 감지
    - 귀찮거나 불편했던 순간을 기록
* 패턴
    - 반복된 사례를 모아 공통점 찾기
* 후보화
    - 해결 가치가 충분한 것만 솎아내기

### Problem-Target-Solution
* Problem: 문제 상황
* Target: 문제를 겪는 인원
* Solution: 문제 해결 방법

### 차별화 전략
* 가능한 niche한 시장을 노린다 - 서비스 안정화, 고도화 - 이후 인접 시장 확장
* 특정 상황, 타겟'만'을 노리는 서비스
* 좁힐수록 기능의 정확도 상승(단, 의미있는 수준의 데이터 확보 선행)
* edge case 도출 체크리스트
    - 해당 타겟만의 제약
    - 기존 서비스가 커버하지 못 하는 부분
    - 해당 타겟의 상황을 이해하는 이유
    - '왜 우리인가'를 한 문장으로

### 엘리베이터 피치
* 서비스를 단 한 문장으로
* 들어가야 하는 것
    - 핵심 문제
    - 타겟
    - 서비스 카테고리, 정의
    - 경쟁 서비스
    - 차별화 포인트
