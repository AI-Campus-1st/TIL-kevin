# 바이브코딩의 산출물
* 제품 정의서 (개발 기준점)
	- 제품을 정의하는 단 한 문장
	- 문제상황/목표/해결방안 구조화
* 페르소나 (타겟 사용자층의 구체적인 예시)
	- 실명, 나이, 직업 등 구체적인 개인정보
	- 그 사람의 문제 상황 묘사
	- 제품이 문제 상황을 해소할 수 있는지
* 시나리오 (사용 패턴)
	- 의도한 사용 패턴 설계
* 기능 명세서 (기능 목록, 우선순위)
	- 사용 패턴의 각 단계를 기능적으로 분해
* 기술 스택 (사용 기술)
	- 사용 도구
	- 언어
	- 프레임워크
	- 라이브러리
	- 배포 경로

이걸로 나의 의도와 맥락을 명확하게 전달해야 함
* /plan/product.md (제품 정의서)
* /plan/persona.md (페르소나)
* /plan/scenario.md (사용 패턴)
* /plan/feature.md (기능 명세서)
* /plan/technical.md (기술 스택)
