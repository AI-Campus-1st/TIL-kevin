## 1. 한 줄 정의
- `[확정]` 사복을 입어 본 적 없는 20~30대 남성이 상황, 예산, 키, 몸무게와 쉬운 질문 몇 개에 답하면 어울리는 헤어스타일과 옷을 함께 추천받고, 미용실에 전달할 문구와 구매 목록, 스타일 유지 관리 방법까지 안내받는 서비스

### 엘리베이터 피치 `[제안]`
교복, 군복, 근무복만 입다가 갑자기 꾸며야 하는 남자를 위한 첫 스타일링
어려운 용어를 몰라도, 쇼핑몰을 뒤지지 않아도 질문 몇 개에 답하면 미용실에서 할 말, 살 옷, 매일 유지하는 법까지 알려 드림

## 2. Problem
### 2.1 문제 정의 `[확정]`
| 구분 | 내용 |
|---|---|
| 판단 문제 | 자신에게 무엇이 어울리는지 모름 |
| 실행 문제 | 옷 이름, 헤어 용어를 몰라 검색, 구매, 미용실 요청을 못 함 |
| 유지 문제 | 한 번 꾸며도 매일 같은 모양으로 재현하고 관리하는 법을 모름 |

- 공통 제약: 패션을 공부할 의지와 경험이 부족하며 누군가 알아서 정해 주길 원함

### 2.2 현재 대안과 한계
| 현재 대안 | 한계 |
|---|---|
| 미용실에서 "알아서 해 주세요" | 결과가 미용사에 따라 다름, 손질법을 모르면 다음 날 재현 불가 |
| 친구, 가족에게 질문 | 상대의 취향과 지식에 의존 |
| 유튜브 코디 영상, 마네킹 착장 구매 | 본인 체형, 얼굴과 무관한 일반론 |
| ChatGPT 등 범용 LLM | 질문을 잘 해야 함, 결과가 일반론 수준이고 실행 단계가 구조화되어 있지 않음 |

### 2.3 근거 `[미정]`
- 현재는 기획자 본인 경험 기반. 기획자 본인 사용 결과를 1차 근거로 활용 예정

## 3. Target
### 3.1 타깃 정의 `[확정]`
- 20~30대 남자
- 옷 종류나 헤어스타일에 무지함
- 고등학교, 군대, 직장 등에서 정해진 옷만 입고 살아서 사복을 입을 기회가 없었음
- 대충 살아서 그동안 꾸민 적이 없음
- 소개팅, 면접 등 외관을 꾸며야 하는 상황이 발생함
- 자기관리를 위해 외관을 신경 쓰기 시작함
- 잘 모르니 일단 저렴하게 세팅하려고 함

### 3.2 타깃의 핵심 축
- 나이가 아닌 '사복 경험 부족'이 공통 축
- 보유 사복이 거의 없는 상태에서 시작한다는 전제

### 3.3 사용 계기 유형 `[제안]`
| 유형 | 예시 | 니즈 | 서비스 내 역할 |
|---|---|---|---|
| 이벤트형 | 소개팅, 면접 | 기한 있음, 일회성. 빠르게 완성된 한 벌 | 첫 사용 계기 |
| 자기관리형 | 외관 관리 시작 | 지속적. 기본 옷장 구성과 반복 가능한 관리법 | 지속 사용 계기 |

- 이벤트형으로 처음 사용하고 자기관리형으로 이어지도록 구성해 일회성 사용 완화

## 4. Solution
### 4.1 핵심 가치 `[확정]`
- 헤어스타일과 옷을 함께 추천
- 추천한 헤어를 미용실에 그대로 전달할 문구 제공
- 추천한 옷을 예산 안에서 바로 살 수 있는 구매 목록 제공
- 추천한 스타일을 유지하는 관리 방법까지 안내
- 사용자는 용어나 패션 지식 없이 따라가기만 하면 됨
- 다양한 선택지를 제공하기보다 선택지를 최대한 압축해 사용자가 느끼는 부담을 최소화
- 헤어와 옷은 손질이 최소화되는 방향으로만 출력

### 4.2 산출물 `[확정]`
| 산출물 | 내용 |
|---|---|
| 헤어 추천 | 어울리는 헤어스타일과 선택 이유 |
| 미용실 주문서 | "미용실에 이렇게 말씀하세요" 문구와 함께 출력하는 시술 요청 내용. 예: "투블럭, 옆머리 6mm, 윗머리 가위컷, 다운펌" |
| 옷 추천 | 선택한 복장 유형에 맞춘 착장 세트 (상의, 하의, 신발 등) |
| 구매 목록 | 품목별 상품명, 추천 사이즈, 가격, 구매 링크, 합계 금액. 합계는 선택한 예산 구간 이내 |
| 관리 가이드 | 헤어 손질법(드라이 방향, 왁스 양 등), 커트 주기, 옷 관리법 |

### 4.3 사용자 흐름
| 단계 | 내용 | 상태 |
|---|---|---|
| 1. 상황 선택 | 소개팅, 면접, 출근, 일상 중 선택 | `[확정]` |
| 2. 복장 유형 확인 | 캐주얼, 비즈니스 캐주얼, 정장 중 상황에 맞는 유형이 미리 선택된 상태로 제시. 사용자는 확인하거나 필요할 때만 변경 | `[확정]` |
| 3. 예산 선택 | 10만 원 단위 가격대 구간 중 선택 | `[확정]` |
| 4. 신체 수치 입력 | 키, 몸무게 | `[확정]` |
| 5. 주관 기준 질문 | 얼굴형, 모질, 체형을 용어 대신 사용자 경험으로 묻는 질문 | `[확정]` |
| 6. 결과 | 헤어 추천과 미용실 주문서, 옷 추천과 구매 목록 | `[확정]` |
| 7. 관리 가이드 | 헤어 손질, 커트 주기, 옷 관리 | `[확정]` |

- 제약 조건(거부 항목, 손질 시간)은 사용자에게 묻지 않음. 손질 최소화 방향 출력으로 대체 `[확정]`
- 기능 단위 상세와 우선순위: [1_functions.md](1_functions.md)
