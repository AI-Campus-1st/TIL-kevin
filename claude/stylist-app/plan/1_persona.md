# 타겟 사용자를 묘사하는 예시 사용자 설정

- 타겟 사용자층을 묘사하는 인적사항, 문제 상황, 서비스 사용 목적을 가정한 예시 사용자 설정
- 구체적인 예시 사용자를 통해 타겟 사용자층을 명확하게 설정하고 AI가 이해할 수 있음


### 예시 사용자 1
#### 인적사항
- 이름: 김민석
- 성별: 남자
- 나이: 26세
- 직업: 취업준비생
- 디지털 UI 친숙도: 보통

#### 본 서비스를 사용할 근거
- 서비스 사용 목적: 취업 목적의 면접에 어울리는 스타일로 코디하기 위함
- 상황: 취업 준비생으로서 당장 면접이 다음주 예정이라 면접에 어울리는 복장과 스타일로 급하게 꾸며야 함. 패션을 공부할 시간이 없음.
- 심리: '당장 다음주 면접인데 어떻게 꾸며야 하지?'

#### 예상 이용 패턴
- 이용 성향: 단기 집중형. 면접일까지 일주일 안에 결정, 구매, 커트를 모두 끝내야 하므로 1~2회 집중 사용
- 관심 순서: 무엇을 살지 > 언제까지 준비해야 하는지 > 면접 당일 어떻게 손질할지

| 단계 | 예상 행동 | 사용 기능 |
|---|---|---|
| 1. 상황 선택 | '면접' 즉시 선택 | 상황 선택 |
| 2. 복장 유형 확인 | 정장과 비즈니스 캐주얼 사이에서 망설임 | 복장 유형 선택, 상황별 권장 안내 |
| 3. 예산 | 취준생이라 최저 구간 선택 시도, 정장 가격대를 보고 상향 여부 고민 | 예산 선택 |
| 4~5. 신체, 질문 | 빨리 결과를 보고 싶어 빠르게 넘김. 모르는 항목은 "모르겠음" 선택 | 키, 몸무게, 주관 기준 질문 |
| 6. 결과 | 구매 목록을 가장 먼저 확인하고 배송 소요일을 따짐. 미용실 주문서는 커트 직전에 다시 열람 | 구매 목록, 미용실 주문서 |
| 7. 관리 가이드 | 면접 당일 아침 손질법 위주로 확인 | 관리 가이드 |
| 이후 | 합격 시 출근룩을 위해 재방문 가능 | 상황 재선택 |

#### 난관 지점
| 지점 | 내용 | UI, 흐름 시사점 |
|---|---|---|
| 복장 유형 선택 | 정장과 비즈니스 캐주얼 중 무엇이 맞는지는 지원 업종, 기업 문화에 따라 다르지만 그 차이를 모름 | 업종 예시(금융, 공기업, IT, 스타트업 등)별 권장 유형을 선택지 옆에 안내 |
| 예산 충돌 | 정장 한 벌, 셔츠, 구두, 넥타이까지 갖추면 최저 예산 구간을 넘기 쉬움 | 예산 초과 시 우선순위(꼭 사야 할 것, 나중에 사도 될 것) 표시, 청년 정장 대여 제도 등 대안 안내 검토 |
| 시간 제약 | 배송 2~3일, 정장 바지 기장 수선, 커트 후 머리가 자리 잡는 시간까지 고려하면 일주일이 빠듯함 | 면접 날짜 입력 시 역산 일정(주문, 수령, 수선, 커트, 당일 손질) 체크리스트 제공 검토 |
| 정장 사이즈 | 정장은 어깨, 소매, 기장 오차에 민감해 키, 몸무게만으로는 사이즈 실패 가능성 높음 | 정장 선택 시 수선 필요 여부와 매장 수선 안내를 구매 목록에 함께 표시 |
| 입력 단계 부담 | 급한 상황이라 질문이 많으면 중간에 이탈할 가능성 | 진행률 표시, 질문 수 최소화, 건너뛰기 허용 |
| 당일 재현 | 커트 직후와 달리 면접 당일 아침 혼자 손질했을 때 모양이 안 나올 가능성 | 관리 가이드를 '면접 당일 아침' 같은 상황 단위의 짧은 단계별 안내로 구성 |

### 예시 사용자 2
#### 인적사항
- 이름: 황원태
- 성별: 남자
- 나이: 22세
- 직업: 대학생
- 디지털 UI 친숙도: 높음

#### 본 서비스를 사용할 근거
- 서비스 사용 목적: 대학 생활에 어울리는 스타일로 코디하기 위함
- 상황: 군대 전역 후 복학, 그동안 군복만 입고 사복을 입은 경험이 적음, 최신 패션을 따라가고 싶음
- 심리: '복학하면서 이참에 제대로 꾸미고 대학생활을 해보고 싶다'

#### 예상 이용 패턴
- 이용 성향: 탐색형, 반복 사용. UI에 익숙해 입력 단계는 빠르게 통과하고 결과를 여러 번 바꿔 보며 비교
- 관심 순서: 요즘 유행하는 스타일인지 > 여러 벌 돌려 입을 수 있는지 > 가격

| 단계 | 예상 행동 | 사용 기능 |
|---|---|---|
| 1. 상황 선택 | '일상(대학생활)' 선택 | 상황 선택 |
| 2. 복장 유형 확인 | 망설임 없이 캐주얼 선택 | 복장 유형 선택 |
| 3. 예산 | 학생이라 낮은 구간 선택하되 여러 벌이 필요해 고민 | 예산 선택 |
| 4~5. 신체, 질문 | 빠르게 응답. 결과를 보고 응답을 바꿔 다시 추천받는 시도 | 키, 몸무게, 주관 기준 질문 |
| 6. 결과 | 추천이 최신 스타일인지 확인. 마음에 안 들면 다른 추천 요청, 마음에 드는 결과는 저장하거나 친구에게 공유 | 헤어 추천, 옷 추천, 구매 목록 |
| 7. 관리 가이드 | 헤어 손질법 위주로 확인 | 관리 가이드 |
| 이후 | 계절이 바뀌거나 새 학기마다 재방문 | 상황 재선택 |

#### 난관 지점
| 지점 | 내용 | UI, 흐름 시사점 |
|---|---|---|
| 현재 머리 길이 | 전역 직후라 머리가 짧아 추천 헤어스타일을 당장 할 수 없을 가능성 높음 | 현재 머리 길이 입력 추가 검토. '지금 가능한 스타일'과 '몇 개월 뒤 목표 스타일'을 단계별로 제시 |
| 트렌드 기대 | 최신 패션을 원하지만 정형화된 추천이 평범하게 느껴질 가능성 | 스타일 취향(무드) 선택 단계 추가 검토. 이미지 중 마음에 드는 것을 고르는 방식 |
| 단일 세트의 한계 | 주 5일 등교에는 한 벌이 아닌 돌려 입을 수 있는 옷장 구성이 필요 | 착장 세트 1개 외에 '기본 아이템 N개로 만드는 여러 조합' 형태의 결과 검토 |
| 계절 | 복학 시점(봄, 가을 학기)에 따라 필요한 옷이 다르나 현재 흐름에 계절 입력 없음 | 현재 날짜 기준 계절 자동 반영 또는 계절 선택 추가 |
| 결과 비교 | 여러 번 추천받으면 이전 결과를 잃어버림 | 결과 저장, 이전 결과 비교 기능 |

### 예시 사용자 3
#### 인적사항
- 이름: 이재욱
- 성별: 남자
- 나이: 28세
- 직업: 무직
- 디지털 UI 친숙도: 보통

#### 본 서비스를 사용할 근거
- 서비스 사용 목적: 오랫동안 사회생활을 안 하다가 다시 시작하기로 하면서 외관을 깔끔하게 정돈하기 위함
- 상황: 오랫동안 집 안에만 있어서 나의 외관에 대해 전혀 신경쓰지 않고 더럽게 지내다가, 이대로 살면 안 되겠다 싶어서 다시 집 밖으로 나가서 사회생활을 하려고 함
- 심리: '밖에 나갈려면 좀 꾸며야 하는데, 뭘 어떻게 해야할 지 아무것도 모르겠다'

#### 예상 이용 패턴
- 이용 성향: 신중형, 느린 진행. 단계마다 머뭇거리고 한 번에 끝까지 진행하지 못할 가능성
- 관심 순서: 최소한 무엇부터 해야 하는지 > 돈이 얼마나 드는지 > 매일 어떻게 유지하는지

| 단계 | 예상 행동 | 사용 기능 |
|---|---|---|
| 1. 상황 선택 | 소개팅, 면접, 출근 어디에도 해당하지 않아 망설이다 '일상(자기관리)' 선택 | 상황 선택 |
| 2. 복장 유형 확인 | 무엇을 골라야 할지 몰라 권장 안내에 의존해 캐주얼 선택 | 복장 유형 선택, 상황별 권장 안내 |
| 3. 예산 | 무직이라 최저 구간 선택 | 예산 선택 |
| 4~5. 신체, 질문 | 최근 체중 변화로 몸무게가 불확실하고, 자기 체형을 의식해 본 적이 없어 "모르겠음" 다수 선택 | 키, 몸무게, 주관 기준 질문 |
| 6. 결과 | 미용실 주문서를 가장 중요하게 활용. 구매 목록은 최소 구성만 구매 | 미용실 주문서, 구매 목록 |
| 7. 관리 가이드 | 커트 주기, 세탁 등 기초 습관 위주로 반복 확인 | 관리 가이드 |
| 이후 | 구직 활동 시작 시 면접 상황으로 재방문 가능 | 상황 재선택 |

#### 난관 지점
| 지점 | 내용 | UI, 흐름 시사점 |
|---|---|---|
| 상황 선택 | '사회생활 재시작', '기본 정돈'에 해당하는 선택지가 없음 | '처음부터 기본 정돈' 같은 상황 선택지 추가 검토 |
| 자기 인식 부족 | 주관 기준 질문에 "모르겠음"이 많아 기본값 의존도가 커지고 추천 정확도가 떨어짐 | "모르겠음" 비율이 높을 때 무난한 범용 스타일 위주로 추천하고, 그 사실을 결과에 안내 |
| 미용실 방문 장벽 | 오랜만의 대면 상황이라 미용실에서 말을 꺼내는 것 자체가 부담 | 미용실 주문서를 휴대폰 화면 그대로 보여 줄 수 있는 큰 글씨 카드 형태로 제공 |
| 예산 제약 | 최저 구간에서도 모든 품목을 한 번에 사기 어려울 수 있음 | 구매 목록에 우선순위 표시, '이번에 살 것'과 '다음에 살 것' 구분 |
| 중도 이탈 | 한 번에 끝까지 진행하지 못하고 중간에 앱을 닫을 가능성 | 입력 진행 상태 자동 저장, 다시 열었을 때 이어서 진행 |
| 관리 지속 | 오랫동안 관리 습관이 없어 가이드를 읽어도 꾸준히 실천하지 못할 가능성 | 커트 주기 알림 등 가벼운 리마인더 검토 |
