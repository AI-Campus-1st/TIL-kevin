## 1. 설계 원칙
- 서비스 방침: 다양한 선택지를 제공하기보다 선택지를 최대한 압축해 사용자가 느끼는 부담을 최소화
- 결과는 항상 하나: 헤어 1개, 착장 1세트, 구매 목록 1개. 종류별 비교, 복수 추천 없음
- 사용자가 '고르는' 항목은 상황, 복장 유형, 예산 세 가지뿐. 복장 유형은 상황에 따라 미리 선택된 상태로 제시해 확인만 하면 되도록 구성
- 서비스가 대신 정할 수 있는 것은 서비스가 정함
  - 계절은 현재 날짜로 자동 반영
  - 헤어와 옷은 항상 손질이 최소화되는 방향으로만 출력. 사용자에게 제약 조건을 묻지 않음
- 입력은 2분 안에 끝나는 분량을 목표로 함

## 4. P0 기능 상세

### F-01 상황 선택
- 목적: 사용자가 가장 쉽게 답할 수 있는 질문으로 시작해 이후 선택 부담을 줄임
- 동작: 네 가지 선택지 중 하나 선택
  | 상황 | 복장 유형 기본값 |
  |---|---|
  | 소개팅 | 캐주얼 |
  | 면접 | 정장 |
  | 출근 | 비즈니스 캐주얼 |
  | 일상 | 캐주얼 |
- 쓰임: F-02 복장 유형 기본값 결정, 결과 화면 안내 문구 (예: "면접 당일 아침에는")
- 저장 값: `date` / `interview` / `work` / `daily`

### F-02 복장 유형 확인
- 목적: 복장 유형을 입력 단계에서 사용자가 결정하되, 고르는 부담은 최소화
- 동작: F-01 상황에 맞는 기본값이 미리 선택된 상태로 표시. 사용자는 그대로 다음으로 넘어가거나 필요할 때만 변경
  - 선택지마다 어울리는 상황을 함께 표기 (예: "비즈니스 캐주얼: 출근, 자율 복장 면접")
- 저장 값: `casual` / `business_casual` / `suit`

### F-03 예산 선택
- 목적: 구매 목록의 합계 상한 결정
- 동작: 10만 원 단위 구간 중 하나 선택
- 규칙: F-02 복장 유형의 최소 구성 비용보다 낮은 구간은 비활성화하고 사유 표기. 예산 초과 상황 자체를 입력 단계에서 방지
- 선행 결정: 예산에 포함할 비용 범위 (8장)

### F-04 키, 몸무게 입력
- 목적: 사이즈 추천과 체형 기본값 산출
- 동작: 수치 입력 (cm, kg)

### F-05 주관 기준 질문
- 목적: 얼굴형, 체형, 모질을 용어 없이 파악
- 동작: 용어 대신 경험으로 묻는 질문. 문항당 1화면, 선택지는 그림 위주
- 문항 (총 5개)
  | 항목 | 질문 예시 | 쓰임 |
  |---|---|---|
  | 얼굴 길이 | "얼굴이 길다는 말을 들어 본 적 있나요?" | 헤어 |
  | 턱선 | "턱이 각진 편인가요?" | 헤어 |
  | 모질 | "아침에 옆머리가 뜨거나 곱슬기가 있나요?" | 헤어, 다운펌 필요 여부 |
  | 어깨 | "셔츠를 입으면 어깨가 꽉 끼나요?" | 옷, 사이즈 |
  | 복부 | "배가 나온 편인가요?" | 옷, 사이즈 |
- 규칙
  - 모든 문항에 "모르겠음" 선택지 제공. 선택 시 키, 몸무게 기반 기본값 적용
  - 응답은 고정된 선택지 값으로만 저장 (자유 텍스트 금지). 향후 사진 분석 경로가 같은 값을 출력하도록 하기 위한 설계 제약

### F-06 헤어 추천
- 목적: 어울리는 헤어스타일 결정
- 출력: 헤어스타일 1개, 참고 이미지, 선택 이유 한 줄
- 규칙
  - 매일 손질이 최소화되는 스타일만 후보로 사용
  - 후보가 여럿이면 서비스가 하나로 결정. 사용자에게 선택을 넘기지 않음

### F-07 미용실 주문서
- 목적: 용어를 몰라도 미용실에 원하는 시술을 전달
- 출력: "미용실에 이렇게 말씀하세요" 문구와 시술 요청 내용, 참고 이미지
  - 예: "투블럭, 옆머리 6mm, 윗머리 가위컷, 다운펌"
- 표시 방식: 미용사에게 휴대폰 화면을 그대로 보여 줄 수 있도록 전체 화면, 큰 글씨 카드

### F-08 착장 추천
- 목적: 복장 유형에 맞는 옷 조합 결정
- 출력: 착장 1세트 (상의, 하의, 신발 등)와 착용 예시 이미지
- 규칙
  - 현재 날짜 기준 계절 자동 반영. 사용자 입력 없음
  - 다림질, 손세탁 등 관리 부담이 적은 소재와 품목 우선

### F-09 구매 목록
- 목적: 쇼핑몰을 뒤지지 않고 착장 세트를 바로 구매
- 출력: 품목별 상품명, 추천 사이즈, 가격, 구매 링크, 합계 금액
- 규칙: 합계는 F-03에서 선택한 예산 구간 이내
- 선행 결정: 상품 데이터 확보 방식 (8장)

### F-10 관리 가이드
- 목적: 추천 스타일을 매일 재현하고 유지
- 출력
  - 헤어 손질: 드라이, 왁스 사용을 짧은 단계별 안내로 제공 (예: 1. 머리 감기 2. 드라이 방향 3. 왁스 양)
  - 커트 주기: 다음 커트 권장 시점
  - 옷 관리: 세탁, 보관 핵심만 품목별 한두 줄

### F-11 최근 결과 다시 보기
- 목적: 커트하러 가거나 구매할 때 결과를 다시 확인 (입력 재진행 방지)
- 동작: 마지막 결과 1개를 기기에 저장, 시작 화면에서 바로 열람
- 규칙: 결과 이력, 비교 기능 없음. 회원가입, 로그인 없음
